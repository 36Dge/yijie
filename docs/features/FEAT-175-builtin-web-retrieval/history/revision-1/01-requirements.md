# FEAT-175 需求与场景

## 事实与范围

用户明确要求默认原生问答、按需专业检索、专家正常联网和其他用户开箱可用。本轮选择了服务端托管凭据与原生只读自动执行。它们覆盖 FEAT-162 仅在市场选中后才能用、强制每次业务审批的原范围；不会撤销其他平台写工具的授权和审批。

本期不增加浏览器自动化、登录态抓取、用户自定义代理、搜索引擎选择器、全文索引、跨任务检索缓存、自动容灾、多级研究 Agent 或新计费套餐平台。保留现有按量供应商计费；仅实现公开运行必须具备的资格、用量上限和调用记录。

## 路由规则

| 场景 | 首选／必要工具 | 不应产生的操作 |
| --- | --- | --- |
| 无外部信息需求：改写、翻译、基于已给材料回答 | 直接回答或现有本地工具 | 因新能力常驻而例行搜索 |
| 普通时效问答 | 原生 web_search | 为显示“使用工具”再执行同需 Basic／Pro |
| 多来源研究、事实核对、报告资料、指定站点／日期的调查 | Pro 必须承担所需材料获取 | 把原生来源列表当作已经交付 Pro 正文片段 |
| 只要官网、标题、摘要、链接列表 | Basic，include_content=false | 普通列表先 Pro 再 Basic |
| 明确收集网页正文供用户处理 | Basic，include_content=true | 默默用摘要冒充正文 |
| 读取已给定且明确要求阅读的 URL | Fetch | 把仅出现 URL 当作读取意图；把搜索命中当作已读全文 |
| 研究后还需核对某页完整当前正文 | Pro 后按需 Fetch | adapter 自动抓取全部结果 URL |
| 专家普通咨询／研究 | 与对应普通任务相同 | 单凭 expert.role 非空就禁用搜索 |
| 专家要求其业务平台的数据 | 保留该专家已配置的平台工具 | 内置网页检索替代账号内经营数据／执行受限写入 |
| input-only 草案／标题 | 不暴露 hosted 和内置网页工具 | 依靠提示词声称工具已关闭 |
| 用户明确设置 web_search=disabled | 尊重原生 hosted 禁用；MCP 仍按自身产品权限 | 将这一原生字段误说成关闭所有网络或所有 MCP |

“首选”不等于不可出错的自然语言分类。服务端端点映射和参数检查是确定性的；模型是否选择正确工具要通过实际评测。必要工具失败时须说明缺失证据，不能静默改路由完成等价宣称。

## 用户流程

1. 打开 App，使用正常易界产品会话；没有搜索连接器安装、授权、Key 输入或选用流程。
2. 输入问题／资料采集要求／URL，专家可选但不改变通用网页能力。
3. 模型沿原生工具系统选择路径；默认只读操作自动执行。运行中沿现有真实工具活动展示查询或页面读取。
4. 供应商返回结果，模型继续作答，保留实际 URL、正文可用性和截断信息。
5. 用户可正常停止；停止后不自动续跑、补发或再次扣费。已发送请求的费用结果以服务端记录为准。

## UI 与失败行为

| 状态 | 产品行为 |
| --- | --- |
| idle | 原聊天输入框、专家选择、附件交互；不新增 Basic／Pro／Fetch 模式选择器 |
| loading | 使用原生搜索／MCP 工具活动；不展示旧市场租约的 23 秒倒计时 |
| waiting approval | 只有原生策略确实要求时显示既有确认面板，参数与当前调用对应；不再有第二次 Broker 批准 |
| success | 搜索来源或结构化网页结果，再给最终回答；工具成功不自动等于结论正确 |
| empty | 明确“未找到结果／该页无可读取正文”，不伪造 URL 或自动扩大查询 |
| partial | 显示正文缺失、截断、丢页；模型可以用已有材料给带限制的结果 |
| permission / quota denied | 说明易界服务资格／额度状态；不要求用户配置 Kimi Key，不默默改用其他收费路径 |
| service unavailable | 普通文本与未依赖此工具的功能仍可用；需要该材料的任务报告限制 |
| retry | 仅用户明确重试或证据显示条件已改变时新发起；历史查看不是执行入口 |
| cancel | 复用 turn/interrupt、MCP 取消；在请求发出前取消为零上游请求，发出后不承诺免计费 |

复用现有主题、1180×760 布局、键盘焦点及结果展开组件；不增加工具专业参数表单、设置向导或开发术语。页面展示新来源要消费明确契约，不能按任意 JSON 外观猜类型。

## 默认与偏好

默认可用是新装应用能力，而非给用户伪造 installed/authorized/selected 记录。旧市场状态保留用于历史读取，退出旧选集不自动产生任何检索。现有原生搜索设置、产品账户禁用和撤权继续生效；web_search 字段只控制 hosted，不扩张为整个网络的开关。旧第三方连接器的启停、卸载、授权及专家图片／视频规则不随本需求变更。

内置网页服务适用于正常根聊天及已验证专家上下文。子代理只能按原生已有有效 MCP 继承／配置使用，不为本需求全局打开继承所有第三方连接器；若实际配置不允许子代理使用，主代理获取材料后按原生协作机制传递，不另造子 Agent 调度器。
