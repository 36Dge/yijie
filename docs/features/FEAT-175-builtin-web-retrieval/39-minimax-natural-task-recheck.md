## 本次进一步确定的原因

三个实际会话均收到新的 Host developer 指令，包括资料元数据可支持列表、按当前工具描述选路、约束整个最终答复，旧“未选连接器就走原生”的句子均不存在。该指令片段 SHA-256 为 `213fd77fb82b454ba9433001db5f37f97dba768870c95f621dbd3058935bce76`。

因此，当前不能继续简单归因于旧 Host 提示词或 Basic 执行器不可用。R01 的公开开场就把任务扩展为“抓取页面实际内容确认摘要准确”，随后主动选择正文参数；R02 只核对了短摘要长度，之后再扩展终稿。实际问题仍包括**把资料列表升级为正文核验，以及把局部摘要合规当成整个答复合规**。本轮没有读取或引用模型私有推理来断言内部原因。

R01 多余并发中出现一次网关 `busy`，在既有 5 秒等待后返回，未创建 API operation／派发供应商请求。真实服务日志另外记录 3 次 HTTP 504、2 次 HTTP 404；这些是现有诊断直接观察，不能把它们改写为 App 本机超时，也没有理由为多余查询扩大超时、并发或追加自动重试。
