## 根因与范围

当前 Basic 描述涵盖标题/摘要/链接列表，但 Pro 描述以“普通联网问答、事实核查、研究、总结和 RAG 材料直接使用 Pro；不要先 Basic”开头，未明确排除单纯列表交付。两个适用范围对模型不够互斥。此判断有两个真实失败及源描述支持；不声称可读取模型内部决策。

在 Contracts tools.json 给 Pro 增加明确前置分流：用户仅要求网页标题、摘要、链接列表，未限定站点/日期且不需要问答或分析时，使用 Basic，不使用 Pro。Basic 同步明确该列表意图的优先级。保留筛选问答、无筛选问答、正文采集和 Fetch 的既有能力；不改原验收输入、不强制 tool_choice、不删工具、不新增模型分类器。
