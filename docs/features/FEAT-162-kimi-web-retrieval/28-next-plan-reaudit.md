## 停止链实现前补充决策

沿既有Host `GET /v1/agent-sessions/{id}`核验冻结case所属session与Runtime请求的thread/turn，随后只调用既有`POST .../turns/{turn}/interrupt`。该正常入口在Host中先撤销对应Broker lease，再请求Runtime正常中断；本轮不新增权限协议、Tauri command或Runtime补丁。meter仅作为既有Owner API的显式适配消费者，凭据由明确指定的现有Owner凭据文件读入内存，不记录/转发到供应商；限定127.0.0.1，不跟随重定向。新控制仅可读映射和中断，不能审批或重试REST。

先关闭后续模型准入，再同步请求准确回合中断；204仅记录Host确认，超时/拒绝/标识不符记未确认。停止后的工具响应不再向Runtime转发。已经发送的调用仍可能收费，原生搜索事件项不是精确收费次数，不能据此减少未知预占。普通loopback适配测试与实际App→Host→worker证明分开登记，未完成后者不解除live资格门禁。此复用不改变既有API语义；FEAT-162整体breaking管理不变。
