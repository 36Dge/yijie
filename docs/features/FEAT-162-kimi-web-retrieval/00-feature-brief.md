用户在普通对话中选用一个Kimi网页检索连接器；模型依据交付结果选择Basic、Pro或Fetch，返回可引用的材料。复用已有Kimi模型Key，不重复配置、不新增模式设置页或额外分类模型。仍为61目录项/62容量、选集上限58。

范围：Basic默认摘要及显式include_content正文、Pro站点/时间过滤与chunks、Fetch公开URL；原逐次审批、权限/撤权、费用、同源真实客户端及正常历史重开。非目标：无头浏览器、JS控制、原始HTML、登录态网页、知识库/向量库、递归爬虫、定时扩权、Runtime内核修改、数据迁移和生产发布。

## 2. 选择规则与主流程

| 用户结果 | 工具行为 |
|---|---|
| 标题/摘要/链接列表、找官网 | Basic摘要 |
| 搜索正文供自行加工 | Basic include_content=true |
| 普通联网问答、研究/总结、RAG材料，即使无筛选条件 | 直接Pro，不先Basic试探 |
| 限定来源或时间 | Pro并显式传约束 |
| 阅读给定URL | Fetch；出现URL但无读取意图仍按实际任务选择 |
| 受约束搜索并核对某页当前正文 | Pro→Fetch，URL来自合格结果；不承诺历史网页快照 |
| 先看列表、用户再选一条读取 | 第一回合Basic→列表；第二回合Fetch→回答 |
| 不联网、仅已有材料、未选/停用连接器 | 不调用本连接器 |

用户明确约束优先，能力冲突需说明；不丢弃筛选、不无理由双搜。当前模型沿原tool calling选择，不新建路由Agent。正常入口免登录→已有Key本地准备→当前会话显式选用→模型形成参数→原审批显示工具/完整参数/费用/有效期→一次HTTP→真实材料回灌及来源回答→正常退出重开只读历史。

## 3. UX、结果与期限

复用选择器、审批卡片和工具详情；亮暗token、键盘与1180×760布局保持。新模式逐页content_status为available/unavailable/truncated，分别代表上游材料未被本地裁剪、上游无正文、本地裁剪过；available不承诺完整网页。顶层dropped_results记录原始结果减最终结果，truncated表示任何丢页/裁剪。默认Basic/Fetch不增加这些字段，不改变旧归一化语义。

新模式逐项舍弃缺失/不可接受URL或结构无效的页面，保留有效页和原顺序；原始空列表是成功空结果，原始非空全部无效为invalid_response，合法页最小元数据无法交付为response_too_large。缺字段/null/坏类型及逐页状态详见22号§3。费用根据过滤前原始响应判断，不能把过滤后空结果记免费。

原始响应1MiB，完整最终MCP包64KiB，包括转义、双份内容、状态和计数；URL不截短。旧Basic摘要/Fetch保留min(剩余时间,15秒)。仅Basic正文/Pro采用30秒上游、35秒HTTP预算：D为各可信截止的最早值，A=D−35秒−2秒投递预留；UI和权威裁决在A禁用/拒绝尚未批准请求，已及时批准者仍受D约束，不因越A误失效。最晚批准窗口理想情况下至多约23秒，实际更短；发送前剩余不足35秒仍零HTTP。MCP起点无法可信核定则不激活新模式，不延长TTL或修改Runtime绕过。

| 状态 | 行为 |
|---|---|
| idle | 原Key本地准备，缺Key、停用和未选清楚，无账户探测 |
| loading | 区分模型/审批/执行，防重复提交、支持正常取消；新模式显示A截止 |
| success | 真实结果/来源可读，工具成功与整轮完成分开 |
| empty/partial | 原始空列表、逐页无正文/被截断、丢页数分别说明 |
| error/denied | 区分模型/工具、限流/鉴权/期限/全部来源无效；拒绝零HTTP |
| retry | 用户新意图、新调用、新批准；无自动重试/换接口 |
| cancel | 发送前撤权；已发送正常收尾、未知费用保留 |

外部内容不作为权限指令，不自动打开URL或下载媒体。历史保留新旧结果；回退关闭新模式但保留兼容reader、默认工具、原Key和数据。
