实现事实
- 八个具名 command 使用 Contracts 生成 Rust DTO；未新增 Cargo/pnpm 依赖。
- exact local/demo_fast/enable gate + 原生固定主体/workspace.use；status/list/create 和独立 run/query 无 editor 前置依赖。
- 仅固定 http://127.0.0.1:18888 的具名 API 路径；禁用环境代理、HTTP 重定向、自动 HTTP 重试；无 renderer URL/header/token 输入。
- K_NA 从绝对配置路径安全读取：普通文件、当前 euid、0400/0600、单链接、1 KiB 上限、O_NOFOLLOW、读前后元信息核对。测试临时文件直接正常创建为 0600，无 chmod/错误属主/权限故障。
- 测试 token/E 均由运行时 CSPRNG 生成，无硬编码 token fixture/default/example；日志与 Debug 不输出机密。
- E 由生成的 EditorSessionSecret 专门直接反序列化，立即移动到现有 Zeroizing SecretValue；不构建 E 的 serde_json::Value 中间副本。返回 editor 视图无 secret/session_id。
- E 绝对 300 秒与 monotonic deadline；保留服务端 expires_at_ms，native deadline 始终不晚于请求开始 monotonic+300s。05/源没有要求主机与容器时钟严格同步，服务端稍领先导致 remaining>300s 时正常接受但仍按该本地上限封顶，不扩大 TTL。每次 exchange 校验当前 bridge/generation/epoch/有效期；到期拒绝 exchange 并清本地 E；close 不需要 E，保持幂等。已取得有效解码 session 后的安装流程统一返回 Result，所有不能安装分支（含时间读取、generation 与视图校验失败）都在释放状态锁后正常 DELETE。
- input/response 按同步 schema 校验 UTF-8 字节限额、字段/未知 enum/协议版本/具名操作；操作的必需和可选字段取源 x-operation-* 与 required。列表只含源生成的摘要。
- 写操作 ID 由 native UUIDv7 生成；不确定错误保留原 operation_id，不自动重复 HTTP 写；相同 editor request_id 不重复写；operation 查询校验原查询 ID。
- context revision 在 open 第一次 await 前捕获；上下文失效、epoch 更换、正常退出及匹配 binding 的 close 推进 revision；迟到 open 正常 DELETE 新会话，不重新建立失效 binding。上下文失效先清已有 binding，再 best-effort 正常 DELETE；服务不可达时不恢复 binding，由服务端绝对 TTL 封顶。
- app 正常退出先关闭 workflow 会话，再走既有 Chat shutdown；关闭 editor/到期不取消真实 run，不删除工作流业务数据。
