## 工程事实与实施决定

- 当前说明文字已经使用Logo主色#C3F35B，白底观感偏浅。用户随后明确选择仅此处采用品牌深绿#4B651D；暗色使用#C3F35B保持可读性，原Logo和按钮不变。
- 当前创建为总览内表单，编辑器和结果/历史嵌在同一页面；真实卡片结构与既有四张示例不同。
- 使用`/workflows/new`和`/workflows/:workflowId`独立内容页面，保留App侧栏。创建使用一次明确点击产生默认名称的新合成文本流程，成功后replace成资源URL，返回不再次创建。已创建但打开失败时保留资源ID，仅重试打开；未知创建结果保留原查询入口，不重复创建。
- 原Coze iframe、native MessageChannel、300秒会话和重连草稿保持不变；compact native标题/返回操作与画布占满内容区，结果/历史通过独立可关闭面板查看。
- 总览从真实列表投影相同卡片信息，按更新时间降序显示于四个既有方案示例之前。真实卡片可以点击或键盘进入对应编辑页；示例不伪装成已实现ERP。宽内容区4张、最小窗口2张，卡片保持可读尺寸，多余卡片在区域内部横向滑动，提供具名前后控制。
- 新深链复用`workspace.use`和既有exact-local开关。原Chat路由/数据/权限语义不变；未保存离开、未定执行、创建中和关闭撤销沿用已批准规则。

`contract-impact=none`：只改Desktop页面路由、布局和既有响应的展示投影，不改变wire/schema/SDK、身份范围、native command、服务端排序语义、数据库或持久化格式。现有Contracts完整来源固定不变，不需要新源契约。独立页面替代继续内嵌；使用受限的现有Coze，不引入整个上游登录/工作台或新的ERP节点。

## 验收

1. 配色按最终用户选择与亮暗token实现，原Logo/按钮不改色。
2. 创建一次→独立Coze→编辑保存→返回，新资源第一张→卡片重开，同资源/内容保持。
3. 图标、分类、名称、说明、修改时间布局与参考卡统一；超过可见卡数可横向滚动，键盘可进入真实卡片。
4. 普通服务未就绪/打开失败可恢复；已创建资源不重复创建；未保存离开可取消；新深链不绕过权限。
5. 定向类型/路由/状态/UI检查，以及真实App、亮暗/最小尺寸验证分别如实记录。旧D4只证明旧候选；本次验证结论在本页追加。
