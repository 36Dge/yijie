## 1. 产品规则保持

- App 携带38项普通技能源，安装App后技能页即可展示；全新用户0项已添加、0项启用，去掉自动安装7项Starter。
- 点击加号从App携带的本地源安装，成功后默认启用，无服务端下载。
- 导入ZIP或大小写不敏感的SKILL.md仅在本机处理，成功即安装并启用，不再点一次安装按钮。
- 已有安装、停用选择和历史保持；App升级新增技能仍默认未添加，不批量卸载或重新启用旧项。
- 页面仍称“技能”，保留五类内置分类、三列卡片、彩色图标、亮暗主题和本轮选择。增加“内置技能／我的技能”及“导入技能”。

正常卡片仍用加号表达未添加、开关表达启停，不恢复常驻版本／许可等底栏。下架、来源丢失、状态未确认和依赖缺项属于真实异常，提供明确管理和恢复入口。

## 3. 用户流程

### 内置展示与添加

App Resources保持完整发行源。应用在本机准备原生市场目录及不可变来源快照，只准备来源不等于安装技能；不会给未添加项创建插件缓存或启用配置。Runtime读取两个固定本地市场，Host映射中文展示，页面显示全部内置卡片。

点击加号：记录意图→按稳定ID解析本地source→原生plugin/install→原生状态与技能快照核对→提交成功回执→开关开启。超时进入“结果尚未确认”，不直接重复安装或报告失败。停用只改原生配置，卸载只通过原生接口；内置源和当前目录卡片保留。

Runtime不可用时可浏览已核验的随包展示索引，但安装状态为待同步、管理操作禁用，不伪造未安装或可用。

### 个人导入

一次一个技能：ZIP根目录一个SKILL.md，或唯一外层文件夹下一个SKILL.md。保留references／scripts／assets等配套结构；正常目录和macOS附属项按规则归一化。无入口／多入口显示格式错误。单文件保持正文，仅规范入口名，依原生规则要求frontmatter和description，不调用模型改写。

流程为读取→校验／原生预检→等待安全提交窗口（若有任务正在使用资源）→原生安装→核对→发布“我的技能”条目并提示已启用。prepared目录条目不表示上传完成；用户无需追加安装动作。脚本、MCP依赖、hooks等不在导入时执行或获得授权。

相同内容已经安装时去重并保留当前启停；同名不同内容创建独立身份，不覆盖。已卸载内容再次显式导入复用历史身份但增加安装操作epoch，默认启用，旧取消请求不能删除新安装。个人卸载不删除用户原文件、运行产物或原生plugin data；仍被迁移／回滚／历史引用需要的来源快照保留。

### 更新、下架与回滚

Host只发布经核验的目标来源并请求原生N3；版本比较、缓存替换与错误汇总由现有原生刷新器负责，停用项更新后仍停用。活动任务与新turn提交共用维护门闩，不能检查一次空闲就无锁替换。

App移除某项技能时，已安装者仍在管理视图，标“已下架／不再随应用更新”，可停用／卸载；未安装者不再提供新增入口。来源丢失也不隐藏现存安装。

旧版本恢复使用同一固定市场根内已核验的来源快照，切换source后调用原生刷新并核对，再提交路由／目录结果。不会把“备份文件存在”当成可恢复，也不会直接写Runtime缓存。

## 4. 职责与最小增量

| 层 | 负责 | 不另建 |
|---|---|---|
| yijie-skills | 内容、许可、版本、原生manifest与展示映射的同源生产 | Runtime执行或安装服务 |
| Desktop | 选择文件、卡片与操作状态、当前轮结构化选择 | 目录扫描器、安装器、正文拼接 |
| Host | 受控来源、发布事务、身份／操作意图、兼容迁移与UI投影 | 缓存版本算法、安装事实数据库、技能匹配器 |
| Runtime | 安装／卸载／配置／版本刷新／库存解析／发现与执行 | 第二套同等机制；只补薄接口和触发边界 |

原生增量为三组，撤回“只有两个小字段”的简化描述：N1本地来源与显式刷新触发策略；N2独立安装事实查询；N3已有刷新函数桥接。N2包含cacheVersion等事实，旧列表installedVersion字段仅可作为方便展示，不能承担恢复权威。当前可调用wire以实际Runtime canonical schema和Contracts投影为准。

ZIP归一化、产品身份映射、来源快照和目录发布事务属于应用输入／产品适配，不接管原生安装。更新器、原生配置优先级、正文读取和按需加载继续复用。专家资源分支保持独立，普通技能writer退役不能破坏专家。

## 5. 状态与权限

| 状态 | 行为 |
|---|---|
| idle | 加号／真实开关与导入入口 |
| loading | 读取、预检、等待任务结束、添加、同步分别说明，同市场变更排队，不造百分比 |
| success | 原生事实确认且发布事务提交后显示成功 |
| empty | 我的技能导入引导；搜索空结果可清除 |
| error | 区分格式／超限／权限／状态不一致／无源，保留已安装项与恢复入口 |
| retry | 同operation_id先查事实并重放结果，不能重做已完成安装 |
| cancel | 提交前撤暂存；提交后持久取消意图、核对并只补偿本次新安装，未知则明确尚未确认 |
| permission denied | 可读则保留目录，管理禁用，沿用Host身份边界 |

安装、启用、Runtime可见和工具就绪分别表达。工具依赖继续绑定已有MCP／连接器真实授权和当前上下文；不自动安装任意server、不新增平台授权。历史正文不删除；旧短名不保证成为新命名空间别名，新发送优先结构化{id,version}。
