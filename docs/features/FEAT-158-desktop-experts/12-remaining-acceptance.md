Connectors现仍仅对固定Shopify URL、精确无id/params完成通知进行兼容；接受已观察到的定长或单个chunked形式，最多读取4字节并要求完整EOF，且字节必须精确为null。其他方法、SSE、标准202/204与其他已知长度JSON维持原路径。分块JSON完成通知若不是精确null会拒绝；没有通用JSON重写、Runtime修改、权限扩大或业务许可放宽。新增诊断只记录固定方法枚举、响应类型布尔分类、长度数值/计数与分块头存在性，无原始header、正文或凭据。
