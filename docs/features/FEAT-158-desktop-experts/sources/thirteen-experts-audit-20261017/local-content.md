- environment-setup/SKILL:182–187是floating `remotion@^4.0.0`、React19安装；该“根渲染项目”无package/锁文件，配置/TSX是模板按会话生成。:316提sudo npm install、:399远程shell Homebrew、:538–540切镜像清cache升级全局npm，不沿易界canonical依赖策略。要固定经审查的可复现本地渲染依赖/浏览器版本，独立任务工作目录，不修改宿主全局环境；缺依赖先标不可渲染，不能拿npx临时下载充当已支持运行时。
- rules/remotion_video_generator_rules.md:19–61说只在规格处确认、后续全自动；主SKILL:238–299另设storyboard review；environment要求安装确认。适配统一规格/素材/执行权限后流程，权限仍宿主审批，包内规则不能覆盖。
- 字体说明默认Alimama/DouyinSans/Montserrat、:末段自动curl main.zip，但没有任何字体实体；`@remotion/fonts`、`@remotion/media`被引用，环境初始安装清单未完整覆盖这些用法。模板/规则中maps、3d、Lottie等还各有可选依赖，首版明示只验收已固定子集，逐模板按package依赖核对。
- BGM `skills/bgm-library/scripts/bgm.js:25`、`downloader.js:12` 硬编码 `rejectUnauthorized:false`。不得原样运行，必须恢复证书验证；当前可先不纳入联网BGM，只用用户授权本地音频。

- Lucide脚本取GitHub main，BGM联网外部源，未纳入易界selected connector流程；首版离线固定许可图标/用户素材就够，不需要运行下载CLI。

### 验收核心

最后/独立环境组：规格明确的15–30秒无网络素材视频，真实生成MP4；ffprobe核对尺寸、fps、时长、codec；抽帧与首尾播放确认内容无空帧、中文字体无缺字，音频如有则合法来源和时长；保存TSX、分镜JSON、依赖锁与产物receipt；修改文字另存重渲；正常停止预览与清理，不强杀进程。无环境时“代码交付可用/渲染待完成”不能叫视频专家真实接入验收完成。
