悬停或键盘聚焦显示“召唤”；触摸等无 hover 输入也能发现主操作。正文开详情，召唤按钮阻止冒泡，不能一次点击同时执行两种操作。长名称可省略并查看全称。

## 详情与快捷问题

截图中的 v1.1.0、6,872 使用量、开发者与十年经历属于参考产品。易界只展示真实版本；没有数据依据就省略使用量、开发者链接和经历。内部 ID 可为 `jd-ops-expert`，不表示 Runtime 已注册了同名 Agent。

三条候选快捷问题：

1. 我刚开好京东店，帮我整理从后台设置到上架的操作清单。
2. 京东快车和全站推广该怎么选？请先说明需要了解哪些经营条件。
3. 帮我检查京东商品上架 SOP，并列出需要到官方后台核实的规则。

点击快捷问题执行同一资源准备流程并填草稿，不调用模型。已有非空正文或附件时提示“保留当前草稿／替换文字”，默认保留，附件不被悄悄删除。普通召唤不自动填入 `defaultInitPrompt`；空草稿可显示建议问题。

## 召唤与草稿去向

| 入口 | 推荐行为 |
|---|---|
| 侧栏扩展中的召唤 | 回首页新对话草稿；保留该草稿内容、模型、工作空间和附件，不改当前旧对话 |
| 输入区“+”菜单中的“选择专家” | 打开同一专家 Tab，携带原对话／草稿上下文；选好后回原位置，不造第二套目录 |
| 已选专家胶囊正文 | 看已选版本详情；主按钮为“已选用”，不悄悄升级 |
| 反复点击同一专家 | 共用一个 operation，一次准备／一次选择，不创建多个聊天 |

PDF 明确侧栏→召唤→首页对话；“+”菜单原位选择是补足已有会话加载的推荐默认值，已随本地实施方案确认。首期没有第二名专家；替换检查使用良性领域数据，不放假专家卡。

召唤包含必要资源准备，不要求用户先理解 Plugin 安装。首期用随应用固定分发的受管内容，不联网抓取未知包。准备中禁重复点击；资源确认后才显示胶囊。失败留在原页提供重试／返回。取消仅取消待选意图：已安全完成的安装可以保留缓存，但不得自动选择、发送或删除其他会话使用的资源。

已选不同专家时提示“将从下一条消息使用新专家，已有聊天保留”，不能叠加角色。运行中、待审批、待投递或结果未知时，不允许完成替换／移除；保留草稿并提示等待或查看状态，不自动中断、不隐藏 fork。

## 胶囊与会话

专家胶囊紧邻店铺授权右侧；当前连接器已收进“+”菜单，所选连接器采用正文行内前缀，保留该实际布局，不恢复旧独立连接器按钮。其他控件按现有响应式布局换行，不覆盖发送按钮。胶囊显示头像和名称，提供“移除专家”可访问操作；× 在 hover 与键盘聚焦时可见。仅选专家没有文字或附件，不可发送。

专家是会话持续选择，FEAT-157 连接器是本轮选择。接受消息后正文和连接器按既有规则清空，专家保留；直到用户移除／替换。新建空白对话不继承，返回已有对话恢复其当前有效绑定和真实状态，不从最后一条历史标签推断。

× 不卸载资源、不删历史、不清空输入，不改变模型、店铺、连接器或权限。已有原生 Thread 的空闲会话先持久化变更意图并显示处理中，保留旧有效绑定；Host 正常重绑成功后才提交普通模式的新 revision 并移除胶囊。无原生 Thread 的草稿可直接修改选择。状态未知时阻止发送并提供恢复，不以标签消失冒充 Runtime 已切换。首次移除可提示：“后续消息不再加载专家设定，已有聊天内容仍保留。”

移除不保证模型忘记已读取知识；其含义是后续请求不再注入旧角色与主动资源入口。需要无旧上下文时使用新建对话。历史保留当轮名称与版本快照，不因卸载改变，也不能点击历史标签恢复执行许可。

## 资源与版本

资源 `available / preparing / ready / unavailable / incompatible` 和会话 `none / selected / applying / ready / unknown` 是不同维度；枚举正式名称由源契约决定。安装成功不等于会话已生效。

安装、扫描、完整性、恢复与资源移除复用 Skills 服务，不新增专家安装数据库。详情次要操作可为“移除本地资源”，与胶囊 × 分开。其他会话有当前绑定、活跃调用或未知投递时，提示先解除引用；初版设计曾设想历史展示快照不阻止卸载；当前单目录资源机制保守保留被历史引用的原版本，并以ResourceInUse阻止卸载，见07实施限定。本期不增加任意版本升级管理器。

会话固定专家版本与摘要。应用升级不能静默换新版：旧版可用则继续；旧版不可用则提示“专家版本不可用，请重新选择或移除”，阻止带此专家发送。重新选择新版显式更新绑定；相同名称重装不继承旧授权或连接器选择。

## 知识与能力

首期是本地知识咨询，不承诺读取京东后台、自动运营或联网核验。详情说明“参考资料含经验与待核实规则，具体平台要求请以适用的官方规则为准”。回答给实际资料的模块、场景、版本与片段定位；缺失内容不能补造。

引用优先复用现有 Artifact／文件查看能力并由 Native 校验路径；若需适配，最小扩展受管资源读取投影。最低验收是当前实际读取的包内资源、内容版本与模块场景／片段可复核，必要时包含该版本行号；原始附件行号只留在内容审校映射，不要求用户引用已清洗排除的原稿。不可做伪链接。点击打开能力作为实现资格检查，不凭现有预览组件推定已支持任意受管路径。

第一名专家无必需连接器。用户额外选连接器时走原管理／授权／审批；召唤不自动安装、启用或开启完全访问。资料缺失不触发隐式付费检索或扩权。

## 状态与恢复

| 状态 | 反馈与操作 | 不变量 |
|---|---|---|
| Idle | 浏览、搜索、详情、召唤 | 浏览无模型调用 |
| Loading | 骨架／准备中，保留原页 | 不提前 ready、不重复操作 |
| Success | 回草稿显示胶囊、聚焦输入框 | 主动发送才创建 Turn |
| Empty | 无专家／无结果，清除搜索 | 不用占位冒充可用 |
| Error | 明确原因、重试／返回 | 保留旧有效绑定，不静默普通发送 |
| Retry | 查询原 operation 后恢复安全步骤 | 已受理消息不创建新提交 |
| Cancel | 关闭详情／取消待选，回原上下文 | 不宣称撤销已发生调用 |
| Permission denied | 保留正文、提示权限不足 | 不自动扩权／借其他会话授权 |
| Incompatible | 移除或选可用版 | 不忽略未知字段继续执行 |
| Busy／待审批 | 等任务／审批结束 | 模型、权限、专家、工具配置串行 |
| Unknown／恢复中 | 查看状态／重试查询 | 不重复发送或伪造终态 |
| 知识无答案／冲突 | 指明缺项和适用条件 | 不选择更有利但无证据口径 |
| 页面返回 | 恢复内存草稿和返回位置，重新校验选择 | 导航不丢当前输入 |
| 正常重开 | 恢复已持久绑定、历史和既有附件状态并重验 | 不新增未发送文字草稿的跨进程持久化承诺；历史不触发执行 |

## 阶段4恢复与异步一致性补充

绑定处保留“查询原操作”，另提供用户显式“恢复原操作”；说明会重新应用原选择，不发送消息。资源页保留查询状态，另提供“处理未完成操作”，确认说明只核对这次操作，确认尚未开始时结束原请求，不重复安装或移除。只有原操作收到明确终态才恢复正常操作入口；恢复调用的错误不能把未知原结果改成失败或成功。

草稿保留/替换、更换专家、资源移除和资源恢复确认都绑定打开时的路由、身份和上下文；导航、身份变化或组件销毁即关闭，旧回调不得作用到新会话。完成回执到达后同步消除原待确认提示；晚到的旧目录快照也不得把终态倒退为待确认。
