## 主流程

1. canonical 本地入口免登录进入易界；打开扩展，默认显示原技能页面。
2. 切到专家，卡片展示名称、京东边界、摘要和标签；正文打开详情，召唤按钮执行选用。
3. 复用受管包准备与校验；资源可用后进入对话草稿，店铺授权右侧显示胶囊。不自动发送或调用模型。
4. 快捷问题只填入草稿。用户检查正文、模型、工作空间、连接器和权限后主动发送。
5. Native 以现有消息／outbox 事务冻结本轮专家身份、资源版本和绑定 revision；Host 验证后经固定 Runtime 执行。
6. 同会话后续消息持续使用同一专家版本；其他会话和新空白对话不继承。运行中、待审批或投递结果不明时不能更换执行绑定。
7. 点击 ×，后续消息恢复普通模式；已有对话和知识上下文保留。排除旧上下文使用现有新建对话。
