## 用户结果

未选专家时，在正常聊天中描述视频或附带图片，即可使用易界内置的`doubao-seedance-2-5-260628`生成一个视频，并在现有视频卡片内播放、拖动进度和保存。用户不安装工具、不填写供应商Key。

显式选定任何专家后，仅按该专家已有工具/权限流程处理；没有视频能力、不可用、执行失败、处理中或结果未知均保留选择并报告，**不切换易界内置视频**。只有用户显式移除/更改专家后的新请求才能改变路由。

## 范围

- 产品归属：应用内置；模型工具族：原生MCP。沿用共享`yijie_media`服务及现有artifact-mcp进程。
- 同一Seedream运营Key、原Keychain条目/HostHome作用域；不新增用户凭据、密钥副本或公网代理。
- 首期支持文本，以及本轮既有图片附件的单首帧、首尾帧、图片参考；实际格式/数量和角色限制见04。
- 固定模型ID；供应商所有可选生成参数省略，采用官方默认值。没有模型/时长/画幅/音频/水印参数面板。
- 供应商异步创建与精确查询、无句柄恢复、同聊天未决防重、正常停止与首次Artifact交付；只保存原root到任务ID的归属及一次交付标记，不保存ACK镜像。
- 复用现有MP4产物、Native ACK、预览与保存，不增加视频任务中心或新播放器。

同聊天存在未决/创建结果未知的视频时先恢复原操作，不在该聊天并发另起；独立生成可使用现有新建任务入口。供应商任务恢复限首次Artifact交付前；交付后保持原Native事实，Host重启不自动重建spool或补领。

不包含视频/音频参考、编辑、延长、Draft样片、素材库、批量生成、供应商任务列表/删除管理、后台自动轮询、跨设备任务恢复、公开视频分发、付费发布、Runtime升级或新Agent执行平台。既有图片行为、专家LinkFox规则不借本需求改写。

## 产品状态

| 状态 | 用户可观察行为 |
|---|---|
| idle | 沿用输入框、图片附件、专家选择；用户表达生成意图后才调用 |
| loading | 原生MCP工具活动显示正在创建/等待；只报告真实排队或运行状态，不造百分比 |
| pending | 一段有界等待仍未结束时说明原任务仍在运行，可继续查原任务；不能说已失败或重建 |
| success | 供应商成功后还需下载、校验、Artifact暂存及Native提交；提交完成才报告已交付 |
| empty/error | 缺有效输入在创建前拒绝；内容拒绝、运营权限缺失、网络未知、交付超限分别说明 |
| retry | 预览/保存重试只读本地产物；任务查询重试只查原ID，不再次创建 |
| cancel | 现有停止按钮停止当前等待和迟到发布；明确供应商任务可能继续，不能承诺远端撤销或免费 |
| selected expert | 保留原专家；无法完成时报告原状态，内置创建/查询/下载均为0 |
