## 实现

- 输入区使用16px通用连接器图标与青柠名称，移除外框、应用logo卡片和常驻关闭按钮。正常单行时与正文同一行；名称太多、太长或窗口较窄时自动换成多行前缀，保留完整输入宽度。
- 保留原生textarea，第一行按前缀实际宽度缩进；后续换行从左侧开始。缩放和窗口变化触发重新测量。长内容滚动时隐藏已滚出可视区的首行前缀。
- 悬停或键盘聚焦名称时图标变为移除图标，点击移除；正文光标位于开头、没有文本选择且不在中文组合输入期间，Backspace移除最后一个连接器。提交/执行时沿用禁用条件。点击移除后恢复正文的光标位置。
- 已发送的用户消息在正文同一段前显示“/ 名称”，每轮只显示一次。通过availableTurns原始名称快照绑定native_observed/native_rebuilt轮次，支持正常重开；不借用当前草稿、改名后的目录或旧Sorftime执行授权。旧生产者缺少索引或超出既有128轮索引时保持原消息显示，不臆造名称。
- 菜单图标由24px缩小为20px；普通选项由40px缩小为32px，异常状态仍可自适应增高。全局开关与本轮选择语义不变。
- 新增语义文字token `--yj-color-connector-mention`：亮色采用较深的青柠文字色，保证白底可辨；暗色使用品牌青柠。其余图标、间距、行高复用现有tokens。
