## 3. 产品规则

## 4. 主流程

1. canonical 本地入口进入易界；打开市场只读目录和状态，不同时连接51个供应商。
2. 浏览/搜索 → 详情 → 安装 → 已安装但未启用；本地依赖准备与安装登记区分。
3. 启用 → 按服务策略完成 OAuth、API Key 或本地凭据配置；供应商资格缺失显示具体原因。
4. 匹配授权 attempt、凭据安全落盘、MCP 初始化及允许工具目录后才宣告已启用；取消/失败有恢复出口。
5. 聊天店铺右侧打开连接器 → 点击已启用行加入标签 → 输入任务并发送。
6. Native/Host 校验 scope、连接版本、权限和时机，与模型/正文/附件一起冻结提交快照；Broker 对每次调用再检查选集与授权。
7. 原生审批/结果沿既有链路展示。停用/卸载禁止新调用；已发出的外部请求不虚称已撤销。历史不因卸载改写。
