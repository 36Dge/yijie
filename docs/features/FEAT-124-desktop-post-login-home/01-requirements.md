## 3. 用户流程

### 主流程

1. 系统完成已有登录态判断。
2. 用户进入桌面端主应用。
3. Router 导航到 `/chat`。
4. App Shell 显示品牌和主导航，“新建任务”处于选中状态；侧栏可在 240px 和 72px 之间切换。
5. 主内容区显示“易界AI”、副标题和任务输入区。
6. 输入为空且未聚焦时，页面按既定顺序轮播 5 条示例 placeholder；用户聚焦或输入后暂停。
7. 用户输入业务需求，文本只存在于当前页面本地状态，不触发提交、网络请求、Agent 或 Runtime。
8. 用户可以进入独立的“任务记录”或侧栏底部 Settings；尚未实现的其他产品导航保持禁用，无权限模块不展示。
9. 用户切换侧栏模式后，选择跨路由和应用重启恢复；偏好异常时安全回退至 240px。

### 失败与恢复流程

1. Session 尚在加载：继续由已有登录层处理；本需求不新增顶部状态或认证 UI。
2. Session 失效：进入已有登录恢复流程；本需求不定义认证协议。
3. 用户无模块权限：导航中隐藏对应模块；直接深链仍由已有授权层拒绝。
4. 路由加载失败：显示可恢复错误状态并提供重试/返回新建任务。
5. 主题或视觉资产加载异常：仍保证核心导航和输入功能可读、可操作。

### 取消、重复与部分成功

- 取消语义：纯导航无异步取消；如果后续包含任务提交，需要另行设计。
- 重试语义：仅适用于 session/路由加载错误；真实任务重试不在当前范围。
- 重复请求：当前 UI-only 范围不产生外部写操作。
- 部分成功：如果 App Shell 成功而业务路由失败，应保留 Shell 并在内容区显示错误状态。

## 5. 状态与错误语义

| 状态/错误 | 触发条件 | 用户行为 | 系统行为 | 是否可重试 |
|---|---|---|---|---|
| session-loading | 已有认证状态尚未解析 | 等待 | 显示明确 loading，不闪现受保护页面 | 自动 |
| ready/new-task | 登录态有效且默认首页完成加载 | 输入任务或导航 | 显示目标首页 | N/A |
| route-loading | 业务模块按需加载 | 等待或返回 | Shell 保持稳定，内容区显示 loading | 自动/手动 |
| unauthorized-nav-hidden | 已有权限投影判定用户无模块权限 | 使用其他可见入口 | 导航不渲染该模块；直接深链仍由已有授权层拒绝 | 否，除非权限变化 |
| session-expired | 已有认证层判定会话失效 | 重新登录 | 进入已有恢复流程 | 是 |
| route-error | 页面加载或渲染失败 | 重试或返回首页 | 内容区显示可恢复错误 | 是 |

## 6. 数据要求

| 数据 | 来源 | 分类 | 租户边界 | 保留/删除 | 日志可见性 |
|---|---|---|---|---|---|
| 登录状态 | 既有认证/会话层，尚待调查 | Confidential | 必须绑定当前用户/租户 | 由认证设计决定，本需求不改变 | 不记录 token/cookie |
| 导航配置 | Desktop 本地代码及权限投影 | Internal | 权限相关项不得跨租户泄露 | 随应用版本 | 可记录路由 key，不记录敏感上下文 |
| 未提交任务文本 | 用户本地输入 | Potentially Confidential | 当前页面实例 | 仅内存；离开页面或应用重启后清除 | 不记录正文 |
| 视觉参考数据 | 合成中文文案，无真实卖家数据 | Internal | N/A | 随设计文档 | 可见 |
| 侧栏显示偏好 | 用户切换 240/72px 模式 | Internal / Non-sensitive | 不绑定租户 | Web Storage 版本化 key；随应用本地数据删除 | 不记录为业务遥测 |

## 7. 非功能要求

| NFR ID | 类别 | 可测要求 | 阻断阈值 |
|---|---|---|---|
| NFR-001 | 可用性 | 1180×760 下无需主体横向滚动即可访问全部关键操作 | 任一关键导航或输入区不可达 |
| NFR-002 | 主题 | light/dark/follow-system 三种设置均可读 | 任一主题出现不可读文本或不可见焦点 |
| NFR-003 | 可访问性 | 键盘操作、语义标签、焦点顺序和 reduced-motion 通过检查 | 主流程存在键盘阻断或缺失可访问名称 |
| NFR-004 | 维护性 | 业务组件不新增硬编码视觉体系，复用/迁移 token 与 Yj* 基础组件 | 页面散落 HEX、magic number 或第二图标体系 |
| NFR-005 | 安全 | 不存储 token，不记录任务正文，不新增原生/网络权限 | 出现敏感信息持久化或越权入口 |
| NFR-006 | 工程质量 | lint、test、build 与视觉检查均有真实证据 | 任一阻断检查失败或 NOT RUN 未获接受 |
| NFR-007 | 动效 | placeholder 切换不超过 160ms，遵循 `prefers-reduced-motion` 且不使用 `aria-live` 重复播报 | reduced-motion 下仍轮播或辅助技术被持续打断 |

## 8. 外部副作用与审批

| 操作 | 影响范围 | 是否写操作 | 审批策略 | 审计要求 |
|---|---|---|---|---|
| 页面导航 | Desktop 本地路由 | no | N/A | 可选匿名页面事件，当前不新增 |
| 输入任务文本 | 仅当前页面内存状态 | no | N/A | 不持久化、不记录正文 |
| 写入侧栏偏好 | Desktop 普通 Web Storage 的单一版本化 key | yes（仅本地、低风险） | 用户主动切换即授权 | 仅写 `expanded｜collapsed`，不记录用户/租户/正文 |
| 创建真实任务 | 不在当前范围 | yes | 必须按既有服务端策略另行设计 | 需要 task/request/tenant/user 关联审计 |

## 9. 非目标

- 实现或重构登录后端、会话、token、Keychain 或租户协议。
- 接通真实任务创建 API、Agent Host、sidecar 或 Codex Runtime。
- 完成店铺、工作台、定时任务、插件和资料库业务页面。
- 修改 Tauri capability、Rust command、CSP、外部 URL 或文件系统权限。
- 引入新 UI 框架、图标库、未批准品牌资产。
- 将参考 HTML、base64 Logo、内联 SVG 或散落 CSS 原样复制进生产应用。
