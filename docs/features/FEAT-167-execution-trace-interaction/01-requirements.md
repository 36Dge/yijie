# FEAT-167 验收标准

2026-11-03 用户批准实施，并明确覆盖旧数据兼容方案。原批准文件保留作历史，现行范围见 sources/current-plan.json。

## AC1 公开说明与原生复用

多步真实任务能显示真实公开阶段说明及最终答案；简单回答不强插过程。无commentary时系统状态与真实活动仍可读，不能伪造模型消息；该降级不算完整模型沟通能力验收。

## AC2 连续活动组

说明A→工具→reasoning→工具→说明B→工具显示为两段说明、两个工具组。32搜索+32推理+8命令无其他边界时只显示一个含40次调用的活动组，真实记录均保留。

## AC3 语义标题与计数

安全原生命令动作能区分读取/搜索文件/列目录/运行命令；来源和工具标题有可信依据；无字段诚实兜底；调用数、动作数、来源数分开。

## AC4 实时与最终状态

当前活动、等待模型、重试、待审批、最终输出、中断和失败互不冒充；未知phase可读而不改写为final；单条完成不等于整轮完成。

## AC5 展开与阅读

整轮、组、必要的单项详情各自可控；同一轮增量不覆盖用户选择；历史默认收起普通过程，最终回答和待用户操作入口可见；键盘和焦点可用。

## AC6 错误、审批与计划

易界保留外层异常摘要/审批入口；willRetry缺失不当false；未完成计划不自动勾选；点击任何阅读控件不执行或重放任务。

## AC7 一致性

started/delta/completed按ID更新；完成快照后迟到增量不覆盖；版本/来源/epoch不混拼；重连及历史恢复不重复文字和动作、不重发turn。

## AC8 新格式与旧入口退役

新会话仅使用Native6/SSE13/IPC6/record6；旧Native接口返回404，旧IPC不注册，旧记录格式明确拒绝；正常停止后清理旧会话数据库和Runtime历史，保留凭据/资源/工作空间文件。

## AC9 视觉与性能

亮暗主题、1180×760、200%缩放、长标题/列表、内外滚动、选中文本、减少动态效果可操作；复用帧合并，未变化事实复用投影；同机测量无解释不了的明显回归。

## AC10 完整产品闭环

受审契约、Host、Native提交、真实提供方、Vue与新格式历史重开形成fresh闭环；仅mock测试不等于真实提供方验收；没有diff设计、入口或新增投影。
