## 本轮实现

- 复用原Yj/Naive/Lucide组件：卡片主体编辑、查看历史/立即运行/删除三个图标、hover/focus tooltip、受控启停开关、按稳定计划ID进入历史；记录主体详情、深链和焦点恢复。
- 表单跨境占位词、“此设备/应用内重要更新”、指定四状态文案；保存后切回计划、清空旧筛选并定位新卡片。有限授权、原生幂等回执、编辑revision、删除及单次/重跑事务继续复用。
- Desktop私有源schema新增一个只读重要更新查询，同源生成Rust/TS/client/validator。只读当前owner/tenant的既有run快照和原生状态，最多50条、需处理优先；无正文副本、无数据库写入、无Host启动或执行授权。
- App全局观察器复用NNotificationProvider，串行轮询、错误退避、scope撤销清理和run/state去重。首开不刷屏旧完成历史；需处理持续显示、完成提示15秒，最多3条。点击进入对应run详情，再用原逻辑验证聊天关联；审批仍在原对话处理。

本轮产品变化仅Desktop 23个文件，含生成物和测试；Host、Contracts、Runtime均与本轮起点逐文件摘要一致，五仓HEAD不变。未新增依赖、第二执行状态机、调度服务、通知中心或跨仓公共wire。整体FEAT为breaking；本次私有新增查询为additive，普通SQL15明确返回storage_disabled。
