## 3. 完整产品规则

### 创建、保存与目标

通过对话创建只预填引导词、保护原草稿；用户发送后才运行受限草案，缺参澄清。native严格校验唯一完整候选，用户审阅确认后与手动表单同源保存，重复确认不重复创建。无效/partial/不确定回复不能假报已保存。草案复用stable outputSchema和已获资格的input-only候选，不新建工具服务。

手动表单含名称1–80字符、内容1–10000字符、跨境占位词、频率/时区/时间、运行于；无高级、加号和项目创建。仅一次为未来日期；每天、工作日（周一至五，不含法定假日判断）、每周至少一天。默认设备IANA时区与每天09:00，可明确更改；保存后时区固定。显示原生时间预览与“此设备/应用内重要更新”。字段错误保留输入，脏草稿关闭需确认。

两种方式都保存为暂停，不隐含授权或立即执行。成功展示权威回执并定位计划，正常重开可读；结果不确定查原请求，同请求显式重试，不重新生成ID。编辑带revision，只影响未来，旧运行保留完整快照。

专属聊天首次运行懒绑定，其后复用会话而每次run/turn独立；每次新聊逐次建立；已有聊天从可访问列表搜索并明确选择。目标删除、无权或忙碌不偷偷换新聊天。plan/run/task/session/thread/turn/operation身份不可混用。

### 管理与执行

既有定时任务导航、两Tab、搜索/刷新、创建时间正/倒序、分页、空态和清空筛选完整。卡片显示真实名称/内容/规则/目标/状态与未来时间；主体可编辑，三个图标为查看历史、立即执行、删除，hover/focus与tooltip/键盘等效。查看历史按plan ID过滤，不按名字猜；已删除历史仍可查。

启用须审阅有限次数、期限、下一次时间并确认；暂停只停止未来安排，不假报终止已开始运行。过期/耗尽/unknown不可暗续授权。立即运行和独立重跑采用最多一次、最长10分钟的单次许可，自动授权/额度保持独立；重跑使用当前配置并展示与历史差异，形成新run，旧记录不改，删除计划不能重跑。

发送前原生重验当前scope/权限/版本/目标/次数/期限，任务沿Ask、不代答审批、不切完全访问。同计划/同会话互斥，定时全局最多一个未释放占用，并与前台共享预约。忙碌跳过或明确拒绝；未知不自动重发，释放需可信原生或正常停止事实，不删预约或假造终态。不承诺跨Runtime exactly-once。

时间计算有界，DST重复一次、缺失跳过，正常可执行延迟窗口60秒；正常重开恢复事实并安排未来，不补跑离线积压。本轮不增加休眠控制或睡眠后发送管理，不承诺设备休眠、退出或关机仍运行。

删除二次确认、默认取消；在途/待审批/未释放unknown拒绝。成功删除停止未来安排，保留墓碑、历史和完整对话；不级联删除聊天/附件，不静默中断执行。

### 历史、通知与可用性

记录筛选按计划当前状态；名称/内容/时间规则使用运行快照。未执行槽不伪造run，已接受不等于完成，执行结束不等于业务成功。失败、需处理、取消和未知如实显示。

详情包含名称/配置/目标、触发方式、状态、真实开始时间与耗时。时间来自固定Runtime（Unix秒、原生毫秒），按运行快照时区显示到秒及偏移；缺失/非法/冲突保持未知，不用排队或本机观察时间代算。完整对话经原生重新核对关联，打开正确session/turn；关联缺失明确说明，不跳错任务。

应用内重要更新全局可见，读取既有持久run/needs_attention事实，按运行和状态在当前scope去重；初次只提示未处理事项，不刷屏旧结束记录。点击打开该run详情，审批仍在原对话处理。关闭提示不释放预约、不代答审批、不授执行资格。无新通知中心、持久正文副本或系统通知。

loading/empty/error/permission denied/unknown有清晰出口；读取失败保留最后确认数据并允许刷新，写入未知先查证。亮暗、1180×760、长文本和键盘/焦点完整，复用Yj/Naive/Lucide及设计token，不重做全局设计系统。
