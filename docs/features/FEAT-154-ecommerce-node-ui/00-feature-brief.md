## 2. 用户问题与结果

- 目标用户：使用易界工作流画布的跨境电商卖家。
- 原始问题：此前本地添加面板仅允许一个文本处理节点；当前已通过原生目录注册30个电商节点。
- 当前用户结果：在原工作流画布点击“添加节点”，按业务分组查找 30 个节点；点击出现卡片，选中后在侧栏填写输入与业务配置、查看输出字段，能理解节点需要什么和将提供什么。
- 本期可交互能力：面板展开/收起、静态目录搜索、添加、选中、拖动、删除新节点、表单填写/展开/切换、同一页面内保留配置。这些仅改变前端界面状态。
- 本期非目标：业务处理、诊断/评分/计算/生成/翻译/审核、数据抓取、真实店铺/规则/模型查询、任何新增业务接口、文件上传与远程媒体加载、节点间执行/调度、可执行图落库、发布/发送、后台自动保存、跨重启恢复、公网及生产。

## 3. 主流程与 UI 方向

1. 通过已有 canonical Desktop 入口进入 `/workflows` 和同窗口 Coze 画布；继承既有 local direct-entry 与固定 scope，R2已实际启动验证。
2. 点击已有“添加节点”，复用真实 Coze `NodePanel`，呈现 30 个节点及简单分组；搜索只筛选本地静态目录。
3. 点击一个节点，在可见画布区域添加独立实例并打开原生侧栏。名称对应文档，长名称在侧栏完整显示。
4. 按“输入 → 业务配置 → 输出”配置。大对象采用中文分组表单/引用选择，不要求卖家编辑原始 JSON；输出只读展示名称、类型和结构，无计算结果。
5. 切换节点、关开侧栏后，同一页面会话内已填内容保留；重复添加同类节点彼此独立；取消删除保留内容。
6. 电商节点为页面内 UI 设计内容。进入该状态前保留原三节点草稿；不将新节点发送给已有保存/试运行/发布协议。离开时提示本次配置尚未持久保存，取消离开继续编辑。推荐方案见 05。

沿用当前 Coze 原生结构、节点轻阴影/淡渐变、图标体系及易界主题。当前工作流局部主色 `#B7F03D`、hover `#B1E83C`、pressed `#ABE03C`；浅色画布 `#F2F3F5` 和原生点阵保持。PDF 的紫色控件与模型示例不是改换主题或启用模型的要求。

| 状态 | 可见行为 |
|---|---|
| Idle | 添加入口、分组目录、普通/选中节点与属性侧栏清楚可辨 |
| Loading | 仅编辑器/前端组件准备；有提示及返回入口，不出现业务执行进度 |
| Success | 已添加、界面配置已更新；不显示采集/生成/审核/上架成功 |
| Empty | 搜索无匹配可清空；未填项有提示；引用候选为空说明“暂无可引用字段” |
| Error | 普通格式问题就地提示；组件加载失败可重试或返回；不引入业务错误码 |
| Retry | 仅重试前端组件或修正表单，不重发业务请求 |
| Cancel | Esc/点外部关闭面板，关闭侧栏不丢配置；放弃/离开需明确选择 |
| Read-only / busy | 沿用既有只读/会话状态，原操作在途时不能切换草稿状态 |

## 6. 推荐取舍与后续边界

推荐复用官方面板、原生卡片/侧栏及主题，以前端电商类型和 30 个稳定目录项区分节点；内存配置不成为可执行图。分组、中文标签、空值与页面内保留是本稿 UI 建议，未冒称原文逐项定义。

全量 30 节点为当前范围，不因 Demo 时间盒自动删节点。后续 30 分钟无新事实扩大只读排查；90 分钟同阻塞评估更简单的进程内适配；非核心检查 120 分钟登记限制；核心阻塞 240 分钟或总计 16 小时仍不满足范围时重新定估时/范围。不可放宽保存白名单、启用网络/模型或缩成静态截图制造通过。

若后续要求保存重开电商图、真实变量求值/执行、上传/查询资源，需另列范围及契约/数据决策；本稿不提前设计这些接口。当前实现与真实检查见14，后续业务能力不在本需求范围。
