## 2. UI-01 添加节点面板

1. 使用原“添加节点”入口与锚定浮层，复用官方 `NodePanel`、`NodeList`、分类、搜索及卡片，保留高度适应、滚动、点外部/Esc 关闭。
2. 30 节点采用原名；01–30 只作需求追踪，不把 nodeType/registry/SDK 等作为卖家主要信息。目录提供图标、名称、简短用途。
3. 推荐五组：商品准备与选品（1–8）、Listing 与搜索优化（9–16）、图片与视频（17–22）、合规与发布（23–26）、店铺运营（27–30）。分组不规定执行顺序/依赖。
4. 搜索只筛选静态名称和简短描述，支持原名中的 Listing/SEO/SKU。清空恢复分组；无结果显示“没有找到相关节点，试试其他名称”。不查远端插件/工作流/模型市场。
5. 全部节点可添加，缺店铺授权、素材或规则以配置空态表示；不借文档业务门禁禁止浏览/添加。
6. 点击遵循原生放置方式，保证新节点可见并尽量不重叠；键盘添加落在当前可视区域。添加后选中并打开侧栏，避免浮层遮挡。
7. 同种节点可重复添加，实例值独立；不沿用“只能一个文本节点”的限制阻止新实例。

## 3. UI-02 画布卡片

- 保留当前原生尺寸、圆角、轻阴影、浅标题渐变及选择/悬停状态；原名过长可省略并提供完整提示。
- 图标沿用既有图标库和局部主题，不引入联网 icon URL 或另造图标体系。
- 输入/输出显示紧凑名称、类型、引用摘要；字段多时折叠摘要，全量在侧栏可访问，不丢字段。
- 左右端口沿用外观。连线/变量引用最多表达页面内配置关系，不新增图推理、执行序、调度、值传播或下游自动填值；新建连线不是本期必须的能力。
- 点击选择正确侧栏，拖动仅改位置；删除仅作用新 UI 实例，有内容使用原生确认，取消保持。既有三节点基线不由本期删除/重写。
- 不新增“运行/生成/上传到平台/审核通过/发布成功”等可触发动作或结果徽标。范围提示用“当前仅配置节点界面，暂不支持保存和运行”。

## 4. UI-03 属性侧栏

复用原生右侧栏：图标、完整名称、简短用途、关闭；主体“输入 → 业务配置 → 输出”，使用原生折叠、标签、控件和帮助。长内容内部滚动，关闭与状态可达。

### 4.1 输入

- 字段、类型、必填/可选取自 04。中文标签为主，变量名/类型辅助；原文说明可在字段帮助中查看。
- 字面值与当前页面已有输出定义的引用可配置；只记录引用，不取数、不求值、不按处理逻辑强制建立依赖。没有候选显示空态，不填演示结果冒充数据。
- 引用组件若依赖远端查询/模型/执行，仅复用静态展示与本地候选部分；不为配置组件解开网络能力。
- object/list<object> 的明示子项用中文小表单/重复行；未定义完整结构则保留引用入口与用途说明，不凭名称猜完整 Schema。
- 规则/策略版本、快照、SKU、素材和店铺都是引用配置；credential_ref/authorization_ref 不改成 token/密码输入框，不请求秘密或宣称授权生效。

### 4.2 业务配置

- 1–8 的独立配置表全量覆盖。9–30 的 diagnosis_config/optimization_config/generation_config 等输入对象展开为配置小组，但保留原字段路径/必填语义，不重复填写两份。
- 仅实现显隐、枚举选择、基本类型、必填提示和列表增删；不实现评分、风险策略、权利核验、预算计算、哈希/版本校验、可发布判定。
- 输入/配置说明中明确的模式或平台差异可用于表单展示；不自动查询平台规则。只在处理逻辑/平台分支出现的规则，不新增为表单/校验。
- 上层 object 必填不代表每个描述中的子项都必填。未明示的子项约束保持未选择/可选，不凭猜测补业务 Schema。

### 4.3 输出

- 只读展示中文名称、原变量名、类型和明示子结构；对象/数组展开折叠。
- 输出章节的 status/report/risk/manifest 字段仍保留为定义，不能漏掉；不计算、不填入“通过”或报告内容。
- “业务结果与错误码”章节完全排除，不转换成状态选项、异常处理配置或结果面板。
- 图片/视频/文件为类型/引用占位；不自动预览生成结果、不抓远程地址。示意内容必须标为示意且不当作实际输出。

## 5. UI-04 控件与默认值

| 原始内容 | 推荐控件 | 限定 |
|---|---|---|
| string/ID/URI/版本/引用 | 单行输入/本地引用选择；明确枚举用下拉 | 不访问URL或核验资源，不默认资源存在 |
| 长文本/描述/提示 | 多行输入 | 不执行，不调用模型 |
| boolean | 开关/复选框 | 无初值时保留未选择，可用显式选择控件；不把未知等同 false |
| integer/number | 数字框及明示单位 | 不猜上下界、币种、精度；不执行计算 |
| enum | 单选/分段/下拉，多选为标签 | 仅明确选项，中文说明 |
| list<string> | 标签/多选/重复行 | 空值不当业务成功 |
| object/list<object> | 折叠小组/结构化重复行/对象引用 | 明示子项可访问，不用唯一 JSON 大框 |
| image/video/audio/file及列表 | 素材引用/占位卡 | 不提供上传/下载/解析/远端播放动作 |
| 日期/窗口/时区 | 日期范围与时区或引用 | 仅文档明示，不预填“最近30天”等业务默认 |
| 输出 | 只读字段树/类型标签 | 无实际值、无执行状态 |

默认值顺序：原文“建议默认值”可作为本稿推荐初值，保留建议属性；枚举首项不是默认；截图值不是默认；“必须指定/当前版本/按策略”等表示待填引用，不能作字面值。9–30 无独立默认表，未明示初值保持未选择。

逐节点特殊项见 04。歧义需区分原文与控件建议，不静默改名、改类型、补上下界或增加隐藏规则。

## 6. UI-05 状态、恢复与可访问性

- 页面内实例/位置/配置/引用相互独立；切节点不串值，关侧栏不重置。
- 搜索无结果、未配置、空列表、空引用都用中性空态，不等同业务失败。
- 普通错误用“填写数字/请选择模式”等可修复说明，不暴露堆栈或业务错误码；修正只表示配置更新。
- 前端组件加载失败沿用错误边界及重试/返回；重试只重建前端。保留同会话内的值，不承诺刷新/崩溃/重启恢复。
- 权限/到期沿用既有只读与重连，重连不写入新节点；不扩大 local gate 或网络能力。
- Esc/关闭只关浮层。应用内将丢内容的页面离开提供“继续编辑/放弃本次配置并离开”；取消保持路由、选择和字段。
- 明确标签、帮助关联、Tab顺序、可见焦点；Enter可添加、Esc可关闭；列表增删按钮有名称，不只靠颜色表意。
- 浅/暗主题、1180×760 和1440×900覆盖长名、长说明、嵌套对象、数组、多语言；主体不意外横向溢出，不一屏塞满工程字段。
- 沿用用户现有颜色，记录新控件实际可读性；不把历史品牌例外当成本期全量可访问性PASS。

## 7. 参考图不带入的功能

不带入付费标记、模型服务、联网、批量执行、异常自动重试、代码/知识库/插件；不运行Markdown算法，不发上架/客服/广告/价格/库存操作；不建后台持久化或公共Schema。输出类型定义与配置参数存在，不等于业务能力已实现。
