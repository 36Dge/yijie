### 来源×格式最低覆盖

每个单元独立记录身份、类型、预期内容/信息层级、入口、实际结果与截图/摘要。相同格式的产物通过不能替代已发送附件reader，反之亦然。

| 格式组 | 已提交生成产物 | 已发送附件 |
|---|---|---|
| HTML/HTM | 实际引用→右栏内容；原NSD按T-02B另记 | 真实消息绑定→右栏内容，不用草稿ID |
| TXT、MD、CSV、JSON | 四格式逐项既有投影 | 四格式逐项新绑定读取，验证正文/表格与截断 |
| DOCX、PPTX、PDF、XLSX | 四格式必须真实正文/页面，合法扫描PDF产物必须有页面 | 四格式内容读取各自验证；扫描PDF等当前不允许导入的子集记输入限制，不能借矩阵绕过准入 |
| png/jpeg/webp/svg/mp4 | 原查看器/非右栏行为 | 原已发送附件行为保持；不能要求当前不存在的媒体打开器，详见T-03 |

若某格式某来源经代码核对确实不支持合法接收，登记该来源不适用及准确原因，仍测试现有正常不支持反馈；不能伪造资源或默默跳过受支持格式。输入本就支持而新reader尚未实现时必须记缺口，不可写不适用。

四格式内容样本：DOCX包含标题/列表/正文/表格/普通内嵌图片；PPTX含多页文本表格、纯图片页，并覆盖页数超过9时的真实页序；XLSX含多工作表、shared/inline字符串、合并格、日期/百分比、有缓存及无缓存公式；PDF含文字/表格/扫描页面。逐一核对真实内容、源顺序及只读阅读控件。不能把ZIP XML扁平拼接、模型chunks、原件元信息、空页或不支持提示当正文成功。复杂对象未完整呈现要单列部分预览，不能用普遍降级掩盖基本正文缺失。

容量与分段另验普通文档：至少一个源大于1 MiB且不超过Office/PDF新预算的正常文件可进入正文路径；多批正文、超过首批行列的表格和跨页访问可继续阅读，截断/边界准确；源超预算只记受限状态。页缓存及缩放边界用普通页面验证，不构造危险压缩包或异常解码资源。

## 4. 验证分层、失败与安全

1. 纯值/组件层验证宽度公式、标签归属/上限、身份去重、状态文案和迟到结果；测试目标是行为与边界，不是复写实现。
2. 同源契约/Native层验证资源绑定、已发送附件独立于草稿、旧v1保持、阅读器/隔离策略及正常释放；只用普通文件/合法请求。起草时兼容未证明；最终本地候选同源与真实方向验证见08，仍保持semantic分类，不宣称生产兼容。
3. 一次fresh canonical App运行覆盖10项Must真实主路径、普通不支持/超限的代表性failure及恢复、正常退出；可使用有效的既有真实提交样本。组件通过不代替真实HTML嵌入、拖动或附件链；原NSD文件的内容兼容验证按T-02B单列，不偷换成已执行完整原件端到端。
4. 缺失/过期/权限拒绝/超时等优先使用自然已有安全状态；没有自然样本时可验证纯状态映射或常规异步顺序，不改时钟/数据库/权限、不停止服务制造异常。明确写覆盖层级；必须的真实路径没有执行时保留NOT RUN，不套用前需求的Owner替代批准。
5. 未执行：强杀/故障注入、可执行文件篡改劫持、权限破坏、攻击资源/危险归档。原因：用户永久安全条款。影响：不声称攻击渗透、崩溃恢复或权限故障专项得到验证；按正常关闭、配置/源审查和普通失败替代。
