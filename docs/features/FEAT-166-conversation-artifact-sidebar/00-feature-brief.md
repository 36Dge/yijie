### 范围

- 包含：正式对话页的右栏、开关、多标签、新建空标签、真实文件打开、只读分级预览、空/加载/错误状态、拖动分栏、键盘操作和正常资源释放。
- 文件入口包含任务生成产物卡片、已发送附件胶囊，以及已存在明确身份绑定的文件引用。未发送的草稿附件保持FEAT-165行为；任意正文路径、同名文本和外部URL不自动升级成文件入口。
- 不含：文件编辑、保存/下载、复制按钮、打印、重命名、删除原件、分享/发布、添加回对话、系统打开、浏览器/文件选择器、全屏、标签拖拽排序/固定/批量关闭、跨会话标签、标签持久化、云服务、Runtime能力扩展。DOCX/PPTX/XLSX/PDF正文或页面阅读明确纳入本期，不能退回信息卡交付；不要求完整办公软件、OCR或像素级排版还原。
- “无文件操作”限定新增右侧预览区域；对话流中FEAT-165原有的另存原件入口仍保留。关闭标签不是删除文件，创建标签不是创建文件或新任务。

## 2. 完整主流程

1. 经现有canonical local入口进入正式对话；右栏默认关闭，消息与输入框使用原宽度，头部右侧保留“展开文件预览”图标按钮。
2. 点击按钮，右栏展开。无打开文件时显示空状态；对话头部、消息区与输入区同时缩入左侧，不叠加遮罩或独立窗口。
3. 点击对话中的有效HTML文件引用：自动展开，按R-03选择/创建标签，显示文件名及加载反馈，成功后展示只读页面内容；不会发送新模型请求。渲染方案见OP-01。
4. 点击“新标签页”加号，创建并激活一个空标签；再从对话点击另一个文件，填入该空标签。也可直接从对话打开新文件，由规则新建标签。
5. 切换标签查看其他文件；拖分隔线改变左右宽度，消息锚点、输入草稿与对话任务继续保持。
6. 点击右栏按钮收起；当前页面内保留标签元信息与宽度，释放预览资源。再次展开重新校验并读取激活标签。切换会话、离开页面或重启后恢复默认关闭、无标签。

## 3. 业务规则与交互规格

### R-01 开关与布局

- 在正式对话页头部操作区最右侧放置固定入口，使用易界图标registry和32px图标按钮。关闭时tooltip/可访问名为“展开文件预览”，展开时为“收起文件预览”，并正确设置expanded状态。
- 关闭状态右栏宽0、分隔线不渲染、不预留空白、不保留隐形可聚焦控件。左导航行为不变；不因打开右栏自动收起左导航。
- 打开形成“对话区 | 分隔线 | 预览区”。对话区仍有独立头部、消息滚动和底部输入区；预览区标签条固定、内容独立滚动。输入区不能覆盖右栏或被挤出窗口。
- 新文件生成、消息流入、历史回放不自动展开；只有用户点击可进入的文件或开关按钮才打开。重复点击当前激活且授权/投影仍有效的文件，或其同次请求仍在加载时，只定位标签，不重置阅读位置或重复请求。重新激活后台标签、收起后展开、权限恢复或资源失效后，须重新授权并按需读取。
- 新建任务首页和定时任务草案页不新增预览入口；正式会话已存在但没有文件时，按钮仍可展开空状态。

### R-02 文件身份、入口和排除规则

- 生成产物使用既有owner/tenant/session/turn/artifact身份，且以Native已持久提交的ready为可读条件；已发送附件使用真实session/message/attachment绑定及现有权限/留存校验。不能用文件名、正文、时间相邻或绝对路径猜关联。
- 可读文件的名称区域/胶囊及明确“预览”动作均可点击或Enter/Space激活；不能把卡片内“保存原文件”点击冒泡成预览。
- 图片（包括既有png/jpg/jpeg/webp等）、SVG/SVGZ矢量图类别、视频（包括既有mp4）均不进入右栏。以Native确认类型为主，扩展名大小写无关兜底；未知或冲突类型不可交给HTML执行环境。草稿图片hover与现有图片/视频查看器保持原行为。
- 点击这些排除类型时，无论右栏当前关闭还是已打开，均不创建/替换/激活标签、不改变栏宽；有既有查看器则继续使用，没有已发送点击查看能力则保持原行为，不借本需求新增媒体查看器。SVGZ仅作排除兜底，不新增其导入/解码支持。
- 仍在生成/传输的文件显示真实状态且预览不可用，不读取partial bytes；失败文件也不冒称ready。曾有明确文件身份但当前过期/缺失/拒绝时可打开对应错误标签，保留安全名称及原因，不自动重生成。
- 同名不同ID为不同文件；同一内容的附件与产物若身份不同也不自动合并。既有历史无真实本地绑定时，不新增虚假可点击入口。

### R-03 新标签页与文件归属（本轮新增的完整规则）

| 操作/条件 | 确定行为 |
|---|---|
| 手动展开且标签数为0 | 显示无标签空状态，标签条的“+”仍可见；不自动造文件标签 |
| 点击“+ 新标签页” | 在末尾新增并激活空标签“新标签页”；每次点击新增一页，直到上限 |
| 点击已在本会话标签中的同一真实文件 | 展开并激活既有标签；不重复创建，不覆盖当前空标签 |
| 新文件且当前激活标签为空 | 将该空标签绑定文件，标题替换为安全文件名 |
| 新文件，当前标签有文件或没有激活标签 | 先使用最右侧已有空标签；若没有空标签则在末尾新建文件标签并激活 |
| 点击其他标签 | 切换激活标签并重新授权读取；只允许1份激活预览资源，不缓存后台内容。重复点击当前激活标签按R-01去重 |
| 关闭非激活标签 | 仅移除此标签，当前激活内容不切换；焦点若在被删除的标签/关闭按钮则移至当前激活标签，原在其他区域则保持 |
| 关闭激活标签 | 优先激活右邻，无右邻则左邻；最后一页关闭后栏保持展开并显示空状态 |
| 收起再展开同一页面 | 保留标签顺序、激活ID、类型化阅读位置及最近手动宽度；内容重新授权/读取，不保留隐藏运行页 |
| 换会话/离开正式对话/重启/身份变化 | 清空全部标签及临时阅读状态，右栏关闭；返回旧会话也不自动恢复 |

推荐上限为**每个当前会话10个标签（包含空标签）**。到达上限时加号禁用并提示“最多打开10个标签页，请先关闭一个”；打开未在列表中的文件时，如果存在空标签仍可填入，否则保持原内容并显示同一提示。已有文件定位始终可用。不悄悄关闭或替换用户已有文件。

标签标题单行省略，完整安全名称在hover/focus可读；同名文件用顺序标记及来源说明（已发送附件/生成产物、所属消息）辅助区分，不暴露磁盘路径。标签横向滚动，激活标签自动进入可见区，固定加号与关闭栏入口不被挤走。未激活标签保留身份、状态和滚动值，不保留活跃WebView、文件字节副本或预览租约。

每标签在内存保存类型化阅读位置：HTML/文本/DOCX为内容锚点与滚动偏移；PDF/PPTX为页号、页内偏移、缩放/适合宽度模式；XLSX为工作表真实ID及行列/分段滚动位置。重新授权后仅在同一源身份和Native可证明的内容版本/校验值一致时恢复，并按新页数/范围夹紧；无法证明一致或内容已变化时回到该格式默认位置，不能把旧scroll套到另一工作表。切换标签/收起可保留这些标量值，关闭标签/换会话/身份失效则清除；不缓存文档内容或把阅读位置写入历史。

### R-04 只读定义与HTML边界

允许阅读滚动、纯文本选择、查看器自身的前后页/跳页/缩放/适合宽度及工作表切换、标签新建/切换/关闭、收起栏和调整栏宽，以及错误重新加载。这些只改变阅读状态，不改原件。没有文件修改、保存、导出、下载、打印、重命名、删除、分享、发布、添加回对话、复制按钮或文件操作菜单。系统对可选文字的复制不被伪称为文件导出能力，也不新增应用复制入口。查看器阅读控件与HTML原文中的业务按钮须明确区分。

**只读是用户可执行操作的边界，不直接等同于禁用构建页面内容的脚本。** 文件修改/导出、表单提交、按钮业务动作、链接导航、弹窗、下载和向宿主发IPC均禁止；仅隐藏外层工具栏不满足要求。文档内容与主应用DOM隔离，无网络、任意磁盘读取或持久网站存储。引用同文件内嵌资源沿有界验证处理，外网或任意相对路径资源不自动抓取。顶层图片/视频/SVG文件的排除规则不禁止HTML中合法内嵌的静态图片，不新增媒体播放能力。

OP-01已由用户选定：在不弱化现有HTML隔离策略的前提下允许内联脚本生成阅读内容，同时禁止用户操作文档中的按钮、表单、链接及其它业务控件。需覆盖鼠标与键盘，不能仅靠遮挡指针而留下Tab/Enter操作入口。载体采用何种安全嵌入方式在Native设计时比较，不先规定必须新增某个WebView API、插件或通用文件服务。不能把独立窗口或隐藏网页冒充右栏，不能全禁脚本后用“动态内容未展示”警告替代目标。

复审已通过此前WorkBuddy显示的确切本机来源路径找到`01 NSD服务可视化管理后台.html`，仅按文本读取，没有执行脚本。原文件85,749字节，`recordsBody`静态tbody为空，第2733—2738行由`renderTable()`生成记录行，第3079行初次调用；禁用脚本会缺失该表格，旧“源文件不可得”和“同名无脚本样本即可验收”的前提撤回。脱敏摘要见[复审源快照](references/reaudit-source-snapshot.json)。原件标题、概览与记录表应可读，搜索/导出/查看等业务动作不可执行。实施时分别验证真实生成产物/已发送附件打开链，以及该原件在同一生产渲染器中的本机内容呈现；已有真实绑定可用时优先做原件完整点击链，没有绑定则单列内容兼容证据，不能将组件结果冒称原件附件端到端已通过。普通合成样本可证明通用身份链，不能证明原件表格已展示。原件不自动发送模型/外部服务或复制到仓库；确需新增发送/生成时明确必要性及本需求授权。

### R-05 文件预览深度与反馈

右栏是否能打开与是否已有全文阅读器是两个维度。用户已通过OP-02明确要求Office/PDF正文或页面内容，本期必须补齐下表能力；现状缺阅读器是实现缺口，不是允许降级的理由。信息卡、空页面或“不支持”提示不计作这些格式的成功内容预览。

| 类型 | 右栏内容 | 边界 |
|---|---|---|
| html/htm | 隔离只读HTML页面，允许内联渲染脚本 | 保持可读内容、禁止文档业务操作；不做通用浏览器 |
| txt、md | 有界纯文本；MD按源码显示 | 不执行Markdown中的HTML，不把链接变导航 |
| csv、json | 复用已有安全表格/文本投影 | 不执行公式；列/行/字节截断明确标示 |
| docx | 按源顺序显示正文/标题/列表/表格及普通内嵌静态图片 | 连续阅读流可接受，不要求原分页/字体/浮动布局完全一致；不能把模型上下文或XML扁平拼接当正文阅读器 |
| pptx | 按真实幻灯片顺序逐页显示标题、可见正文、表格及静态图片，标明页号 | 纯图片页也应有内容；不混入备注当正文，不按slide文件名字典序排序；不播放动画/音视频 |
| xlsx | 按原顺序切换可见工作表，显示真实行列/单元格、合并关系及日期/百分比等数值语义 | 不编辑、重算或刷新数据连接；公式用已保存缓存值并标注未重算，无缓存则显示公式和“无已保存计算结果”，不造0 |
| pdf | 按原页序显示实际页面，页码/总页数及阅读缩放可用；合法已接收的扫描件显示页面图像 | 无需OCR或可选文本层；不能因提取不到文字判空成功；不填表、不编辑批注、不跳外链 |
| 其他合法已登记文件 | 已有对应安全阅读器才显示内容，否则同信息状态 | 不添加任意扩展导入/生成能力 |
| 图片、SVG、视频 | 不进入右栏 | 保留已有查看方式 |

生成产物优先复用既有投影；已发送附件通过独立身份授权接入同一阅读能力，不复用草稿专用接口假装支持历史附件。已有格式的限额、TTL、校验及截断保持；Office/PDF确实缺少的正文投影仅在下述新预算和原件准入边界内补齐，不放宽源校验。

Office/PDF的**基础成功范围**为上述真实内容，复杂对象（嵌入文档、SmartArt、复杂图表等）不能静默消失：在原位置显示明确对象类型/未呈现提示并标记“部分内容预览”；若主内容无法展示或纯图片页空白，该文件不是预览成功。附件输入准入与预览支持分开：本期不暗改导入/模型上下文语义，当前拒收的加密PDF/特定结构或无文字扫描PDF附件仍说明原因；合法ready的扫描PDF产物则必须按页面预览。若后续要扩大附件准入，需显式评估输入契约，不能在右栏绕过校验。

容量分层：既有输入10 MiB/生成原件外层64 MiB及更严格结构预检保持；Office/PDF新增预览源建议上限10 MiB，不能误套旧TXT/CSV的1 MiB。OOXML仍受512条目、单条8 MiB、总展开32 MiB约束；PDF仍受256页及既有对象/流限制。正文/单元格按批次读取，单批文本投影256 KiB、结构化文本响应512 KiB，表格单批不超过200行×50列，后续可通过阅读滚动/分段翻页继续访问；不把首批截断叫全文。页图/内嵌图片与文本响应分开计量，复用受权资源原语，仅传有界资源引用，不把图片base64塞进文本响应绕限。页图按需加载，最多当前页及前后各1页，单页/单图预览至多4百万像素，活动页图及内嵌图片解码总量不超过48 MiB；不可见图片按需卸载，超出目标分辨率时在阅读缩放中提示上限。以上新增数值是本期候选实现预算，实施验证后若需调整须更新本包；不得以“文件已接收64 MiB”推导无限渲染，也不得仅返回元信息通过普通正文样本验收。

| 状态 | UI与恢复 |
|---|---|
| idle/closed | 仅对话布局和展开按钮；无后台预览加载 |
| empty（零标签或空标签） | 居中低对比文件图标；标题“当前没有文件展示”；正文“请尝试在对话流中完成任务，生成一个产物；点击对话中的文件，即可在此预览。”；不放生成按钮或文件选择器 |

快速A→B、关闭时仍在读取、连续切标签等都由“会话/标签/请求代次”判定结果归属；迟到结果不能盖住新标签或重新打开栏，取得的资源必须正常释放。当前文件IPC没有cancel操作，投影是普通响应值，Native操作租约在调用内释放，并非交给前端的长期租约。因此本栏最多派发1项读取、保留1项最新待发意图；新点击替换待发意图，旧在途结果失效但正常收尾后才派发最新有效意图。不为每次点击排无限请求，也不为“取消”强杀或新建通用取消服务。复用模块有其他工作占用时尊重原全局限额，映射资源忙。已超时、关闭或会话失效的待发意图不得后来自动执行。只有当前激活标签可展示内容/持有活动视图，后台标签不缓存内容；“单活动展示”不冒称Native旧工作瞬时消失。

读取成功不意味着可无限展示。源文件TTL、预览会话期限、授权revision和本机正常删除事件持续约束展示：对已知到期或已收到的失效，在前台最迟1秒内清空内容并正常释放；Native HTML不得丢失旧实现每秒检查与最长30分钟预览会话的边界。源文件TTL到期不可重读；仅预览会话到期且源文件仍有效时可由用户重新加载。自然后台暂停/系统休眠恢复后，先复核权威有效性再恢复内容，不能先闪出旧页面。单文件失效保留错误标签，仅显示仍允许访问的历史元信息；身份/tenant/权限权威整体失效清空全部标签。现有5分钟Native操作context的正常到期续接须立即释放旧内容、废弃旧请求；若页面路由与已认证tenant、权限revision及读取能力均保持有效，可保留与当前会话历史同级的标签元信息，在替代context重新授权读取成功后恢复内容。此续接不延长源TTL或绕过权限撤回；无法证明同一权限范围时仍清空全部标签。无可证明的元信息授权时显示通用“文件不可用”，不保留名称。新读取边界若缺有效期/失效信号，须在窄契约中补定义，不靠前端猜TTL、不新增磁盘扫描服务。预览故障不改变原任务终态、不阻断继续输入/发送。

### R-06 宽度、拖动与窗口变化

所有尺寸均为**CSS逻辑像素**，不是截图物理像素。`W`为扣除左导航与应用外壳占位后，正式对话工作区的实际内宽；由容器度量，不能用屏幕宽或`window.innerWidth`代替。两侧下述宽度均包含各自内边距。现有窗口默认1268×780、最小1180×760；左导航展开240、收起72。

设分隔线布局宽`D=1`、`A=W-D`。展开所需最小工作区`W=801`，两侧最小400。

```text
rightMin = 400
rightMax = min(1200, floor(0.70 × A), A - 400)
rightDefault = clamp(round(0.60 × A), rightMin, rightMax)
chatWidth = A - rightWidth
chatMin = A - rightMax  （至少400）
chatMax = A - rightMin
```

|---|---|---|---|
| 右栏关闭 | 右栏0；对话W | 沿原页面约束 | 对话W；正文/输入列原上限760保持 |
| 右栏展开 | 右栏目标60%，按上式夹紧；对话取剩余 | 右栏400；对话动态chatMin且至少400 | 右栏rightMax；对话chatMax，无脱离W的固定上限 |
| 消息/输入内容列 | 各自在对话pane内居中 | 随pane缩小 | 仍不超过760；pane小于640时水平留白改16，足够宽时32 |

- 1px视觉线、8px鼠标命中带（覆盖两侧各3.5px，不额外吃布局宽），hover/focus强调色，光标`col-resize`。拖动中连续更新、达到边界夹紧，不自动折叠；拖动与预览内容的指针处理隔离，指针越出预览区域仍能结束拖动。
- 松开保存本页面内手动宽度。双击分隔线或聚焦时Enter恢复当前W下默认值，**同时清除手动偏好标记和值**，之后窗口变化重新按默认比例计算。拖动中Esc/pointercancel恢复本次拖动前有效宽度及偏好状态并释放捕获；正常mouseup提交本次宽度。拖动中发生窗口/左导航尺寸变化或栏关闭时结束本次拖动，按变化后的边界夹紧原偏好，不留下捕获或临时样式。
- 聚焦分隔线后左箭头使右栏增宽16px、右箭头缩窄16px，Shift组合64px；Home右栏最小、End最大。separator可访问名“调整对话与文件预览宽度”，暴露当前/最小/最大值。
- 未手动调整前，窗口大小/左导航变化按默认比例重算；手动调整后保持最近偏好像素宽并按新的上下限夹紧。夹紧不覆盖原偏好，窗口恢复可恢复该偏好。
- 若缩放/异常窄容器使`W<801`，两侧最小宽无法同时成立：临时收起右栏、释放内容资源但保留本页标签/宽度，提示“窗口空间不足，请扩大窗口后打开文件预览”。按钮和文件入口不创建不可见新标签；允许给出该提示。空间恢复不自动弹开，用户再次点击才打开。最小1180×760、标准缩放必须能正常并排，不可借窄宽降级跳过正常验收。
- 不改变原App最小窗口、不强制缩放内容、不用浮层遮住对话、不使整页横向滚动。预览内宽表格/长源码可局部横向滚动。

### R-07 会话状态、可访问性和视觉

- 复用易界主题tokens、Naive UI及YjIcon registry；无新增通用UI库。新增分栏值进入专用layout token，由布局组件承载，不散布魔法数字。已有设计系统320—380px“上下文面板”不作为本文件阅读栏规格。
- 标签条约44px，文件标题信息行约48px；长名截断有完整名称说明。中性背景和细边界区分区域，不复制WorkBuddy品牌/多余工具。亮暗主题保持足够对比，动效服从减少动态效果；拖动不做迟滞动画。
- 使用tablist/tab/tabpanel语义和手动激活：左右键仅移动标签焦点，Home/End聚焦首末，Enter/Space才激活并触发读取；Delete关闭持焦点标签，不能误关另一个激活标签。关闭后的激活/焦点遵循R-03；加号与每标签关闭均可键盘操作。不要注册全局Cmd+W/Cmd+T抢占系统或编辑行为。
- 从文件点击打开后焦点转激活标签，Tab可进入阅读区；标题+加载结果轻量播报，不自动朗读正文。手动收起焦点回展开按钮；窄宽自动收起时，仅当焦点原在被隐藏右栏/分隔线内才回按钮，原在输入框等区域则保持；零标签关闭后焦点回加号；换会话按原页面焦点规则。
- 打开、拖动、切换和收起保持对话阅读锚点、输入文本/附件、发送/停止按钮及流式输出；预览不能获得取消任务或清理会话的权力。
- 生命周期只保存在当前对话页面内存；不新增localStorage、数据库字段、历史重放事件或跨设备同步。关闭页后源文件仍沿现有Native留存期管理。

### R-08 原生机制优先复用（用户本轮新增约束）

- 实施前必须核对`yijie-codex`fork实际源码、工具注册/特性开关和当前消费pin，不能仅凭“fork了Codex”假定具备Codex桌面产品全部阅读器，也不能未检查就从头造工具。本轮核对与精确复用矩阵见[05原生机制审计](05-codex-reuse-audit.md)。
- 继续沿固定Runtime既有exec/apply_patch/工具执行与受管MCP生成文件，沿现有`yijie_artifacts.publish_artifact`登记、Host加密spool/原伴随流、Native校验提交后ACK和原身份授权读取；原artifactId/provenance/顺序/存储/留存均保持。不为右栏新增生成器、发布器、工具注册、事件总线、文件传输/扫描/云转换或第二套存储。
- 文件点击只读取已提交真实文件，不重跑模型、shell、publish或下载暂存原件。原生`fs/readFile`与`view_image`等执行/模型能力不是用户预览授权入口；不得为“复用”绕过Native的owner/tenant/session/文件绑定。
- HTML的隔离策略、文本/表格投影、Office/PDF的结构预检与已有ZIP/XML/解码原语必须优先复用。尚缺的正文/页展示仅补最小阅读投影和同页展示适配，不为每个格式另建MCP工具/生成服务；新增载体、依赖或私有边界须有“已查能力→缺口→最小增量”依据。
- 若当前fork注册/消费配置中没有现成Office/PDF阅读器，应如实记录已查范围，继续复用上述完整机制并补展示缺口；不能删除用户已确认的正文目标，也不能把任意外部MCP或技能文案当成已安装可用的阅读器。
