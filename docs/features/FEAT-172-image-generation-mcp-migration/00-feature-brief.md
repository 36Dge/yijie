# FEAT-172 图片生成入口迁移到应用内置 MCP

2026-11-12，修订 3，已实现并通过本地验收。最新用户调整：“如果用户选定的专家不可用，不再使用易界默认工具做兜底。”该要求取代修订 2 的自动兜底设计；实施与验证继续。

## 产品结果与边界

模型通过应用自动装配的 `yijie_media.generate_image` 使用易界内置 Seedream 服务。无需安装工具、勾选市场服务或输入用户自己的供应商 Key。当前非公开本机部署由运营方预置受管凭据，Host 非交互读取。

选定专家后使用其配置能力，专家、工具、授权或所需输入能力不可用，以及失败、处理中、未知、拒绝或取消，都保留专家选择并报告原状态，不改用内置生图。未选专家的会话使用内置 MCP。只有用户显式更改或移除专家后，新请求才重新路由。

复用固定 yijie-codex 的 MCP、tool_search、Code Mode、审批及继续执行，保留现有 Seedream 客户端、单张参考图与 Artifact 交付。关闭旧原生图片入口，不改 Runtime 源码/二进制/schema。不实现视频、公开服务、媒体数据库、过渡双写或历史迁移。
