# FEAT-126 决策、风险与安全预审

## 1. 决策状态约定

- `Recommended`：Codex 根据当前代码和用户需求给出的候选，尚未得到段成威批准。
- `Ready for Owner Approval`：设计事实、边界和候选文本已完成，可由段成威作接受/退回决定；仍不是Accepted或实现授权。
- `Accepted`：段成威留下明确结论和日期后可作为后续设计输入；不自动授权实现。
- `Open`：不影响继续完善文档，但标注的 Gate 之前必须关闭。
