## 使用隔离候选

在 `yijie-desktop` 仓库运行 `pnpm client:images:prepare` 可通过标准构建命令建立此候选，随后运行 `pnpm client:images:open` 以同构建回执打开独立应用。准备与打开必须采用相同的构建环境。验收时的本地计数器仅用于限定已授权的真实联调，普通候选不依赖该计数器。
