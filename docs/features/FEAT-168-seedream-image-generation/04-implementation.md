## Runtime 接缝与技术审定

固定 app-server 在组装 thread extensions 时已有出站请求通道。内置图像扩展则把 OpenAI 图片客户端绑定在工具内部。现有反向接口 `item/tool/call` 从 DynamicToolCall item 产生，其旧 Host 消费者要求 experimental 开关；借用它会把同一次生图同时表示为动态图工具和原生图像工具。

候选为给原生图像扩展注入一个由 app-server 提供的受管 backend；沿同一已连接的 stdio JSON-RPC 通道，发出单一、限定用途的反向生图请求，以 threadId/turnId/callId、prompt 和本轮参考图选择作输入，返回短状态。保留原生 executor 与开始/结束、Host 的原图暂存及 Native 的持久提交。受管候选与能力均匹配后才开放工具；不开放旧 experimental 配置，不传图片路径、原始图片或密钥给工具。固定上游子树不直接改，使用独立可重放 patch、候选构建目录及 Contracts 投影。针对此改动的技术授权独立于 D0，实际状态以本记录后续更新为准。
