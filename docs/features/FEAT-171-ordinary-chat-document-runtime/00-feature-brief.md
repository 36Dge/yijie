## 1. 用户目标与当前交付

用户要求：易界安装后，普通对话即可生成、解析和预览 TXT、Markdown、HTML、CSV、JSON、DOCX、PPTX、XLSX、PDF；不依赖当前产品中的专家、技能、连接器；应用管理专用环境；参照本机 Codex 桌面应用的装配和实现标准重构，并补齐遗漏。

需求与D0定稿后，Owner确认方案和ADR并授权实施、另批准30元/80次真实模型验收。当前九格式能力及专用环境已落地，Kimi生成与上传修改两场景完成；Owner最新指令取消MiniMax验收，实际调用0。未提交、推送或发布。完整D4仍待清洁安装、最低平台等项目。入口：[Codex审计](03-codex-reference-audit.md)、[易界审计](04-yijie-engineering-audit.md)、[实施设计](05-integration-design.md)、[依赖基线](06-dependency-baseline.md)、[平台与预算](07-platform-resource-budget.md)、[真实验收](11-real-model-acceptance.md)、[Accepted ADR-0024](../../adr/ADR-0024-managed-document-capabilities.md)。

初始审计时，原生产物支持主要覆盖已有文件登记、传输、保存与预览，普通聊天缺少完整托管依赖保证。杭州Word任务两次中间失败后生成成功，但没有走publish_artifact；不能把裸文件链接当作原生产物提交证明。现已接入专用环境和提交状态确认，已有专家OOXML脚本不成为运行前提。

### In scope

- 九格式创建、合法已有文件解析、普通对话后续修改、版本化交付、正文预览、导出及正常重开。
- 全新用户、零专家/市场技能/连接器安装和选择时，文档能力默认可发现、可调用。停用全部可选市场能力仍可完成任务。
- 应用自有指南、模板、脚本和引擎随应用交付；不将现有技能市场服务、专家角色或连接器网关作为隐式依赖。内部指导复用原生扩展点，不能另建Host匹配器。
- 专用CPython单栈、文档库、LibreOffice、应用原生Quartz页面导出、字体及渲染资源，固定绝对路径调用；不默认系统环境，不借用Codex缓存，不改全局PATH或用户shell配置。
- 清洁环境安装候选、升级兼容、依赖来源/许可证/版本/摘要及正常回退。

### Out of scope

- 图片/视频的独立生成产品；文档内插图及内部页面PNG校验仍属文档范围。
- 云协作、OpenAI Spaces账号、完整CRDT编辑器、完整Office克隆、宏/VBA执行、PDF OCR、任意格式互转。
- 公网/付费用户/SLA/多租户生产激活及正式签名分发；须单独完成适用生产治理，不能以本地D4替代。

首期平台固定为macOS 14.0及以上、Apple Silicon arm64原生，最低8GiB内存/推荐16GiB；Intel/Rosetta/Windows/Linux不在首期。平台范围为本轮按用户授权定稿的支持政策，不代表已实测最小系统。安装即用指完整安装候选携带文档依赖，首次使用无需手动pip/npm/Homebrew、Python/Node/Office、源码/编译链或Docker。模型账号与访问条件沿产品原设计，不承诺离线模型推理；已装引擎解析/预览不额外联网。文档就绪不能绑定无关工作流启动。

开发入口成功不算安装验收。完整包为固定默认，首用后台下载不能冒充完整离线依赖就绪。可选资源/升级下载另有真实状态。

### 九格式功能基线

| 格式 | 创建/解析 | 预览和往返要求 |
|---|---|---|
| TXT | UTF-8中文、段落、换行，明确BOM/非UTF-8处理 | 可读全文或有继续入口；另存不改正文 |
| Markdown | 标题、列表、表格、链接、代码围栏；保留源码 | 渲染/源码可检查，代码不执行，后续编辑不破坏围栏 |
| HTML | 自包含静态页面、中文、表格、HTML/CSS样式 | 隔离渲染/源码只读；不执行脚本、无本地/业务桥接，不自动请求外链 |
| CSV | 引号、换行字段、Unicode，明确编码/列类型 | 表格预览；前导零/长数字不擅自转型，公式样文本不执行，导出策略明示 |
| JSON | 对象/数组、Unicode、空值/布尔/数值，语法验证 | 结构/源码可读，有界读取，不静默损失大整数精度 |
| DOCX | 标题样式、列表、表格、图片、页眉页脚、分页、中文字体 | 正文及同源版式可读、生成件逐页视觉校验；原件可编辑，不丢表格图片 |
| PPTX | 标题、正文、表格、图片、基础图表/形状，正确页序/关系 | 同源版式逐页预览/缩放；文字表格保持可编辑，不以整页截图冒充原生PPT |
| XLSX | 多表、类型/格式、合并、基础图表和基本公式 | 表/区域阅读；生成公式有可靠计算结果；解析旧件区分公式/缓存/过期，保存重开一致 |
| PDF | 可提取中文文本、表格/图片、正常分页；读文本页及扫描页 | 翻页/缩放/扫描页显示，无OCR不编造扫描文本，保留原件 |

超出基线的合法文档应报告具体不支持对象，保留原件，不以空内容掩盖解析失败。后续修改限可支持内容；可能丢失复杂结构时停止覆盖并说明，可生成新的兼容副本。DOCX基线支持段落/表格/样式修改，PPTX支持已有基础文本/表格/图片替换与页序调整，XLSX支持单元格/公式/格式/工作表修改，均须保留未修改的基线内容。PDF修改以生成稿源数据再生成及明确授权的页级提取/重排/合并为基线；扫描件无OCR不承诺直接修改扫描文字。视觉目标是参照产品同级可读可审结果，不承诺与Microsoft Office像素级一致。

## 2. 完整主流程

1. 完整安装候选启动，独立检查内置文档环境；local验证沿ADR-0018免登录固定scope，公开产品不继承例外。
2. 用户普通聊天直接提出生成需求或上传文件要求解析/修改，不选择专家技能连接器。
3. 模型通过原生工具/资源机制取得内置指南和经验证的专用入口，按需读取帮助，不常驻全部文档，也不通过Host关键词匹配。
4. 在当前工作区生成临时版本→结构/内容校验→按格式渲染→原生view_image查看页图→修复后重验受影响内容。固定load_document_environment提供受管路径与内置指南，不注册市场技能。
5. 复用publish_artifact→Host spool→Native校验持久提交→ACK。QA文件不作为正式产物登记；只有真实提交的版本显示就绪卡片；模型通过get_artifact_status读取同generation ACK确认，unknown不得假称已持久交付。
6. 点击卡片在原右栏阅读同一版本；最终回答引用真实产物，不凭路径文本宣告成功。
7. 桌面另存复用原生授权与保存；工作区外权限不扩大，拒绝保存仍保留聊天产物；不静默覆盖已有文件。
8. 后续修改基于用户选定版本产生新版本，预览和导出一致；旧引用可追溯，正常重开不重放生成或外部保存。聊天原件保留7天，显示到期日并提供另存；用户已另存文件独立存续，过期不自动重新生成。

## 3. 交互与 UI

沿当前聊天、活动条目、产物卡片与文档右栏设计系统；不新增文档模式，不要求用户配置技术环境。保持亮暗、1180×760、键盘焦点、滚动分页和阅读位置。技术版本/诊断仅在排障详情展示。

| 状态 | 行为 |
|---|---|
| idle | 原输入框；无模板时合理默认排版，不强制选模板 |
| loading | 显示真实执行/校验/交付状态，无事件不造百分比；旧已提交版本可读 |
| success | 真实卡片、正文预览、原件保存和检查说明；生成/提交/外部保存独立确认 |
| empty | 无产物不造卡；非零容器中的空表/空正文与提取失败区分；零字节输出明确暂无可交付内容，不生成成功卡片 |
| error/partial | 明确环境/生成/结构/预览/保存哪个环节失败；多格式逐件保留结果 |
| retry | 有新证据或明确操作才重试失败环节；同版本幂等，未知结果先查询 |
| cancel | 按05新增原生cooperative_only策略正常收尾，保留活句柄及已提交版本；30秒未退出显示STOP_PENDING，不强杀、不假报完成 |
| permission denied | 保留原生拒绝，不自动切完整权限或换工具；仍可读有效产物 |
| environment unavailable | 提供恢复原包/升级指引，不回落系统试错；旧文件阅读尽量独立可用 |

## 6. 推荐方案与停止条件

采用自有可分发运行包＋内置指南/库适配＋原生执行＋既有产物链＋统一预览；参照Codex架构，不复制私有缓存。原专家/技能保留为可选业务能力，不删除或迁移。

12小时目标、16小时硬停止；30分钟无新事实扩大只读审计，90分钟同点阻塞比较替代，非核心120分钟登记限制，核心240分钟复核方案。范围跨安装/引擎/预览，时间盒不构成工期承诺；超时重估，不静默删除格式或安装验收而宣称完成。遇分发资格/原生缺口/权限边界问题先给具体候选，不绕过边界或伪造结果。
