# ADR-0023 — 原生执行轨迹与单一新格式

状态：Accepted（需求与设计决定，实施验收另行记录）
日期：2026-11-03
决定人：段成威；依据为本轮明确实施指令及随后旧数据退役指令。

易界复用 yijie-codex 已有 preamble/commentary、final、commandActions、MCP appContext、error.willRetry 和生命周期；不新增 planner、执行器、重试器或 Runtime patch。Host 只安全投影，Native 只归并和持久化，前端只建立阅读索引。

主流采用公开说明与连续活动组。推理记录保留在组详情，不作为独立主流条目；动作数量不当作调用次数；未知阶段不伪装最终答案；计划、审批、异常和终态遵循原生事实。本决定覆盖 ADR-0016 对逐条主流推理展示的历史要求，不改变事实来源和权限规则。不包含 diff。

采用 Native6/SSE13/IPC6/record6；用户明确允许删除所有旧会话及不迁移旧日常数据库，故原旧版兼容、双通道、SQL43/profile方案取消。V4/SSE11与旧IPC退役，旧格式reader不启用；旧源契约留作历史。一次显式、固定范围的清理必须在易界正常停止后执行，保留凭据、资源和用户文件。此授权不涉及本机Codex自身的历史。

新契约固定完整commit，全部consumer就绪后用固定开发入口激活。不支持旧包读取新数据；需要恢复时保留新数据并向前修复。不得将普通构建当作发布、将mock当作真实模型验收，或用禁止的故障/攻击测试补造门禁证据。
