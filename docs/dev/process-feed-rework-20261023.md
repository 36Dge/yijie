## 修复内容

- 将现有执行说明投影替换为连续工具活动分组，一组允许混合搜索、命令及工具调用。每组只显示一条“执行记录”及实际数量，不再生成重复完成段落。
- 真正的commentary仍独立原文展示，保持“模型进度”来源；无阶段中间消息仍标为“模型消息”。模型消息、用户输入、最终答案与待处理事项切开活动组，保持阅读顺序。
- 展开组后复用原来的网页、命令和工具组件；记录ID、原顺序、输出、来源及复制策略不变，成功但没有输出的命令也可查阅。
- 已确认失败/拒绝以数量标记持续可见，即使整轮折叠；具体错误按需展开。待审批、审批提交/核对/错误、不完整、失联和不可用记录继续独立显示，不塞进折叠组。
- 推理摘要与未知详情继续单独折叠；完全相同的已完成摘要只默认展开首条，原记录仍可单独查看。不会把3条不同摘要删成1条，也不会把3条真实空输出命令当作不存在。
- 只有有效实时观察可产生“进行中”标记。等待模型时保留单一实时提示，终态撤销；冷历史不制造实时进度。用户展开选择和焦点在流式更新、完成时保留，切换轮次重置。

`contract-impact = none`：只改Desktop进程内阅读投影、组件展开状态及测试/设计说明。HTTP/SSE/IPC、原生字段与阶段、数据库、Runtime执行、审批、内容保护、安全投影、引用和原始正文均不变。没有修改yijie-codex固定源码/补丁或Host指令，没有创建另一套执行器；没有新增依赖，没有为原始pandas错误安装软件或重写回答。
