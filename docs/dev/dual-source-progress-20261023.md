## 展示行为

- 原文公共 commentary／已确认排版为中间过程的消息：来源标签“模型进度”。内部推理和摘要
  保持详细记录，不改名，不复制到进度段落；原消息正文与复制结果不增加来源标签。
- 真正的原生活动：在对应记录前显示“执行进度”段落。只说明搜索/读取/查找、命令或工具的
  实际阶段；可汇总相邻同类事实，不能跨模型消息、错误或未知事件汇总。
- 只有当前原生观察才能显示“正在进行”；失联、撤权、切换会话、终态沿现有链路撤销。
- 首个模型输出前显示客观等待说明；收到正文后移除等待说明，不用定时器编造新消息。
- 空命令、重复摘要、审批、错误、最终答案和手动折叠状态沿用既有规则；失败或非零退出码
  不被汇总为成功。系统说明不携带命令、路径、参数、未经核实的研究发现或链接。

新增 `ChatExecutionProgress` 是纯渲染组件；`conversation-process.ts` 是纯只读投影。
不修改 yijie-codex 或 Runtime 二进制，沿用 canonical 标准 App 构建。
