# Service Mounts

This directory is reserved for backend and platform service repositories.

- `yijie-api/`: Go business backend.
- `yijie-agent-host/`: Thin Codex Runtime host and adapter.
- `yijie-connectors/`: External platform connector and MCP tool layer.
- `yijie-knowledge/`: RAG knowledge and retrieval service.
- `yijie-coze/`: Coze upstream workflow engine source and Yijie adapter; repository onboarding in FEAT-153, runtime integration pending.

These are sibling-repository responsibility indexes, not copied service sources.
